# 地図の背景イラスト

ランドとシーの背景は組み込みの画像生成を使って作成しました。概略の位置関係をつかむためのイラストです。ルート・地点・施設名はアプリが別に重ねます。公式のガイドマップは各パークのリンクから開けます。

- `land-map.webp`: ランドの城・街並み・森・山・未来の街。
- `sea-map.webp`: シーの港・火山・水辺の街・森・宮殿。

生成時の指定：正方形の俯瞰イラスト。南に入口、中央付近にランドの城またはシーの火山を置き、既存の概略図と同じエリア配置にする。ランドは青・赤・金、シーはジュビリーブルーとターコイズを基調とする。広い通路と緑を描き、文字・ピン・番号・経路線・ロゴを入れない。描き込みのある柔らかな絵地図とし、ラベルを重ねる余地を残す。

## トップ画

`land-hero.webp` は青空と自然な午前の光の城・岩山・庭園へ変更しました。既存の構図と描き込まれたイラストの雰囲気を保つよう指定し、画像生成で編集しています。`sea-hero.webp` は夕暮れの港のままです。地理地図とは別の雰囲気を伝えるイラストであり、正確な施設配置を表すものではありません。

## TDRouteのロゴ

`tdroute-logo.webp` は利用者から提供されたTDRouteのロゴです。図案・文字・色と縦横比を保持し、Web表示用に縮小・変換しています。作品集のパネル画像は変更していません。

## 地理地図の挿絵

`land-geographic-map.svg` と `sea-geographic-map.svg` は、園の境界・水域・建物・徒歩通路・樹木と土地被覆の実座標を使って描いています。ランドマークの挿絵は透明背景の水彩風の素材として生成しました。ランドではシンデレラ城、ビッグサンダー・マウンテン、美女と野獣の城を描いています。シーでは火山、タワー・オブ・テラー、S.S.コロンビア号、キング・トリトンズ・キャッスル、キャラバンカルーセルが目印になります。

同じ視点と光で描いた建物を一つずつ切り出し、足元を各地物の座標に合わせました。元の挿絵と地表の模様は `scripts/map-art/` にあります。選択した経路は地理地図の手前に重なります。地図の再作成には `python scripts/build_illustrated_maps.py` を使います。
