# 地図の背景イラスト

ランドとシーの背景は組み込みの画像生成を使って作成しました。概略の位置関係をつかむためのイラストです。ルート・地点・施設名はアプリが別に重ねます。公式のガイドマップは各パークのリンクから開けます。

- `land-map.webp`: ランドの城・街並み・森・山・未来の街。
- `sea-map.webp`: シーの港・火山・水辺の街・森・宮殿。

生成時の指定：正方形の俯瞰イラスト。南に入口、中央付近にランドの城またはシーの火山を置き、既存の概略図と同じエリア配置にする。ランドは青・赤・金、シーはジュビリーブルーとターコイズを基調とする。広い通路と緑を描き、文字・ピン・番号・経路線・ロゴを入れない。描き込みのある柔らかな絵地図とし、ラベルを重ねる余地を残す。
