# 公開ブラウザ版

Python教材のCP-SATモデルは `src/park_itinerary_lab/` で管理する。公開ブラウザ版はGitHub Pagesで完結する独立したJavaScriptアプリとして実装する。

- 探索途中の実行可能な案を返せるようにし、最適性を証明していない結果を厳密な最適解と表示しない。
- 徒歩グラフの距離と待ち時間の推定を実測値と混同しない。公式情報には出典と確認日を付ける。
- 実際の購入や在庫照会は行わない。利用者が確認したDPAの時間枠と購入記録を条件にする。
- 必須項目、時間窓、予算、退園、再計画で固定した予定を独立に検証する。
- 公開するWeb資産を `scripts/build_public_site.py` で明示し、学内配布ファイルや入力データを含めない。
