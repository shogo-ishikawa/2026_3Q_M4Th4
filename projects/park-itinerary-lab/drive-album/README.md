# 夢の思い出を個人のGoogle Driveに保存する

Google Apps Scriptを所有者として実行し、投稿されたJPEGをマイドライブの「TDRoute 夢の思い出」に保存します。招待したGoogleアカウントでTDRouteにログインすると、写真を体験に結び付けて投稿できます。写真ごとにアプリでの公開範囲を選べます。アルバムのメンバーはアプリから変更します。Driveのフォルダは「制限付き」のまま使用してください。画像を表示するときもアプリで参加資格を確認します。

## 設定

1. 写真を保存する個人のGoogleアカウントで [Apps Script](https://script.google.com/) に新しい独立したプロジェクトを作成します。Firebaseの管理アカウントとは別のアカウントを使えます。`Code.gs` と `Jpeg.gs` をそれぞれ同名で登録します。
2. プロジェクト設定でマニフェストの表示を有効にして、`appsscript.json` をこのディレクトリの内容に置き換えます。Driveの高度なサービス v3を利用します。標準のGoogle Cloudプロジェクトと関連付けた場合は、そのプロジェクトでもDrive APIを有効にします。
3. 「デプロイ」から新しいウェブアプリを作成します。実行ユーザーは「自分」、アクセスできるユーザーは「全員」です。TDRouteからの通信にはFirebase IDトークンが必要です。写真の保存先となるGoogleアカウントでDrive連携を許可してください。
4. 発行された `/exec` URLをTDRouteの配信用の接続先として設定します。全利用者に配布される接続先は担当者が管理します。利用者が任意の接続先を入力してログイントークンを送ることはできません。公開前にGitHub Pagesから、投稿・表示・削除、招待されていない利用者の拒否を確認します。
5. プログラムを更新するときは「デプロイを管理」から同じデプロイを選び、新しいバージョンを指定します。プロジェクトを作り直すと、既存のアルバムの記録を引き継げません。

## 保存と権限

`drive.file` 権限で、このアプリが作成したフォルダと画像を扱います。サーバーの資格情報はApps Scriptが管理します。Firebaseの接続先と管理者の利用者ID照合値はTDRoute本体と合わせます。別のFirebaseプロジェクトに導入するときはプロジェクトID・公開ウェブAPIキー・管理者照合値を設定してください。

アルバムに参加すると写真を投稿できます。公開範囲の初期値は「自分だけ」です。アプリでは投稿時と同じFirebase利用者IDでログインした参加者にだけその写真と体験名を表示します。写真の投稿者が「アルバムのメンバー」に変更すると、他の参加者も見られます。公開範囲が記録されていない写真は「自分だけ」として扱います。

投稿者は写真を削除できます。管理者はアルバムに共有された写真を個別に削除できます。アルバム全体を削除すると、そこに保存した「自分だけ」の写真も含めてDriveのゴミ箱に移ります。削除を開始すると同行者のアルバム閲覧が止まります。途中で通信が切れた場合は同じアルバムから削除を再試行できます。共有の解除後は新しいリクエストを拒否します。端末へ保存した画像は各利用者が管理します。

アルバム名・参加者のメールアドレスの照合値・投稿者の利用者IDの照合値・写真ごとの公開範囲・画像と体験の対応は専用スクリプトのプロパティに保存します。画像本体に含めるのはリサイズされたJPEGの表示データです。投稿時に位置情報などの付加情報を除きます。ファイルIDや投稿者の名前を表示するDriveリンクは配信しません。実際の旅程・個人の写真・認証トークンはGitに保存しません。

## 招待制アルバムの利用枠

この構成は最大12アルバム、各12人の招待と40枚の写真に対応します。写真は長辺2,048px・1,000,000バイトまでです。アルバム記録をスクリプトのプロパティ上限に収めるための設定で、Driveの契約容量とは別です。通信中にエラーが起きた場合は、同じ投稿IDで再送できます。同じIDを持つ直近の削除済み写真は復元されません。
