# v1.0.0の動作確認

実行環境はPython 3.12.14、NumPy 2.3.5、pandas 2.2.3、scikit-learn 1.8.0、Matplotlib 3.10.8、requests 2.34.2、ipywidgets 8.1.9です。

## 確認した内容

- 新ラボのNotebookは全3コードセルを順番に実行し、操作パネルの「解析を実行」から標準デモを実行。20行の誤差集計、9枚の図、観測履歴と条件を含む結果ZIPを作成しました。
- 既存の発展教材も全42コードセルを同じPythonプロセスで順番に実行し、エラーなく完了しました。
- 自動テスト262件が通過しました。時系列の境界、未来観測の遮断、円周上の風向誤差、静穏、日単位の再抽出、地点の一致、保存・再読込、操作パネルの状態切替を含みます。
- Open-MeteoからJMA MSM・ECMWF IFS 0.25°の最新予報を実際に取得し、辻堂のアメダス観測72時間とともに保存しました。未来の48行は評価0件として処理しました。
- 2026年11月10日00 UTCを初期時刻とする両モデルの過去予報を取得し、同じ辻堂の観測と48行を照合しました。これは接続・照合の動作確認であり、モデル間の性能を結論付ける実験ではありません。
- 合成データのZIPを再利用した将来予測では、予測値と図を出力し、未来の誤差を採点しないことを確認しました。

## 確認環境の範囲

Google Colabの実画面での操作は未確認です。Notebookのコード・ウィジェットと解析の接続は、上記のローカル環境で確認しています。

この検証環境ではJupyterカーネルのソケット作成が禁止されていたため、既存のnbclientによるカーネル実行テスト1件は実行できませんでした。その代わり、両Notebookの全コードセルを同じPythonプロセスで実行しました。262件という件数は、通過した自動テストだけを数えています。

気象APIの接続確認日は2026年11月11日です。提供元の仕様変更、通信状況、観測の公開遅延によって、取得できるデータの範囲は変わります。
