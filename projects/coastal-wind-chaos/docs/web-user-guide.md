# Web版の使い方

Web版は、風の見方と予報の確かめ方を学び、Colabで解析した結果を読み解くためのページです。気象学や機械学習を初めて学ぶ人も、図を動かしながら進められます。

## 最初の進め方

1. 風速・風向の操作を試します。向きを変えたとき、北風がどちらへ進むかを確かめます。
2. 海岸の風と予報が違って見える理由を読みます。地点、地形、観測と予報の時間の違いに注目します。
3. 学習・調整・最終評価を時間順に分ける考え方を確認します。
4. 誤差の体験欄で、予測の偏りや大きな外れを変えます。MAE・RMSE・偏りの違いを見ます。
5. Colabで実際に解析し、保存した結果をWeb版で開きます。

上から通して読んでも、目次から気になる項目へ進んでも使えます。

## 風速と風向を動かす

風速は風の速さで、m/sは「1秒あたり何m進むか」を表す単位です。スライダーで風速を変えると、粒子や数値の変化を確認できます。粒子は、風の向きと速さの変化を示す模式図です。

風向は、風が吹いてくる側の名前です。北風は北から南へ進みます。北を0°として時計回りに測ると、東90°、南180°、西270°になります。359°と1°は、円周上では2°しか離れていません。

粒子や矢印が示す「風が進む向き」と、風向の「吹いてくる側」を分けて読みます。動きを止めたいときは停止の操作を使ってください。端末の動きを減らす設定にも対応します。

気象庁の時別観測で扱う風速は、観測時刻までの10分間の平均です。例えば15時の値は14時50分から15時までを表します。時別データの1行を、1時間全体の平均やその瞬間だけの風と取り違えないようにします。

## 予報と観測の違いを知る

| データ・方法 | 何を表すか |
| --- | --- |
| 観測 | 観測所の測器が、その地点・高さ・時間の条件で測った値 |
| 既存の気象予報 | 広い範囲の大気を数値モデルで計算した予測 |
| 観測からの機械学習 | 過去の観測から学んだ関係を、その後の予測に使う方法 |
| 教材の合成データ | 変化の要因を理解するために、式や乱数で作った仮想データ |

海陸風は、海と陸の温まり方・冷え方の違いによる風です。穏やかに晴れた日の海岸では、昼に海から陸、夜に陸から海へ吹くことがあります。実際の風には季節風、低気圧、地形などの影響も重なります。

海陸風の図では「昼の例」「夜の例」を切り替え、陸と海の温度の関係と矢印の向きを比べられます。この図は仕組みを示す模式図で、選んだ地点の予報を計算するものではありません。

気象モデルの格子間隔は、計算する点の間隔です。格子が細かくても、砂浜の一点や建物の陰の風まで同じ精度で表せるとは限りません。予報を取得した地点と観測所が違う場合は、その差も考えて結果を読みます。

## 誤差の体験欄を使う

ここでは教材用の数値を動かし、誤差指標の性質を確かめます。実在する地点や気象モデルの精度を示す結果ではありません。

| 指標 | 読み方 |
| --- | --- |
| MAE | 予測と観測のずれを絶対値にして平均したもの。平均して何m/s外したかを見る |
| RMSE | ずれを2乗して平均し、平方根を取ったもの。大きな外れの影響が強く出る |
| 偏り | 「予測−観測」の平均。正なら強く、負なら弱く予測する傾向 |

正負のずれが打ち消し合うと、偏りは0に近づきます。それでもMAEやRMSEは大きい場合があります。一つの大きな外れを加えたときは、MAEとRMSEの変化を比べてみてください。

## Colabで解析する

[Colabで風速・風向予報ラボを開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M4Th4/blob/main/projects/coastal-wind-chaos/notebooks/coastal_wind_forecast_lab.ipynb)

1. Colabを開き、必要ならGoogleアカウントでログインします。
2. 「ランタイム」から「すべてのセルを実行」を選びます。
3. 最初は「デモで過去検証」を選び、「解析を実行」を押します。
4. 結果を確認し、「結果ZIPをダウンロード」で保存します。
5. Web版へ戻り、結果ビューアで保存したZIPを選びます。

データの取得、モデルの学習、誤差解析はColabで行います。地点・期間・予測する時間先を変えるときもColabを使います。詳しい操作は[Colabの使い方](forecast-user-guide.md)を参照してください。

## 保存した結果を開く

「結果ZIP・CSVを選ぶ」から、このラボで保存したZIPを指定します。CSVを使う場合は `summary.csv` を選び、`metadata.json` や `skill.csv` があれば一緒に選びます。ZIP内の大きな学習モデルを実行することはありません。

結果ビューアは、Colabが保存した指標を表とグラフで表示します。Web上で学習や誤差解析をやり直す機能ではありません。条件を変更した結果を作るときはColabで再解析してください。

「合成データの例を見る」では、教材の合成データを使った表示例を確認できます。実測値や実在する地点の予測性能として扱わないでください。

### 表やグラフで見ること

- **データの出所**：合成データ、実観測、気象予報のどれを使った結果かを最初に確認します。メタデータがない場合は出所未確認として扱います。
- **地点と予測する時間先**：同じ地点でも、1時間先と24時間先では予測の条件が違います。
- **評価件数**：観測と予測がそろって採点できた件数です。0件の指標は未評価です。空欄を誤差0と読み替えません。
- **条件別の誤差**：月、時刻、風向、風速帯で得意不得意が変わることがあります。区分ごとの件数も確認します。
- **持続予報からの改善度**：「今と同じ風が続く」という予測との比較です。同じ時刻の組で比べた値を読みます。

指標は単位も確認します。風速のMAE・RMSE・偏りはm/s、風向のMAEは度、改善度は%です。風速と風向では、採点できる件数が異なる場合があります。

改善度は、同じ条件の持続予報よりMAEが小さければ正、大きければ負になります。例えば20%なら、比較した組ではMAEが持続予報より20%小さかったという意味です。

改善度の95%区間は、評価した日を取り直したときの推定のばらつきを調べたものです。区間が0をまたぐ場合は、この評価期間では改善の向きがはっきりしないと読みます。将来の風速が入る範囲を示す予測区間でも、別の期間で同じ精度が出る保証でもありません。誤差が時間先とともに増えたことだけから、風の物理的な予測限界を決めることもできません。

### 入力を選び直す

別のファイルを選ぶと、表示を新しい入力に切り替えます。「表示をリセット」で読み込んだ結果を取り除けます。入力の読み込みに失敗した場合は、元のZIPやCSVを確認して選び直してください。

ファイルはブラウザ内で処理し、解析結果をサーバーへ送信しません。共有するZIPに個人情報や公開したくない地点情報を含めていないかは、共有前に確認してください。

## うまく表示できないとき

| 状況 | 対処 |
| --- | --- |
| ZIPを読み込めない | このラボが出力した結果ZIPかを確認する。対応したブラウザで開くか、`summary.csv` と `metadata.json` を選ぶ |
| 誤差が空欄 | 観測がまだない将来の予報や、評価件数0件の結果では正常 |
| 出所未確認と表示される | `metadata.json` を一緒に選び、元の解析条件を確認する |
| 数値を変更して再計算したい | Colabで条件を変えて解析し、新しく保存したZIPを開く |
