# 海岸の風速・風向予報ラボ：使い方

海岸の風は、いつも同じ予報どおりに吹くのでしょうか。このラボでは、予報を並べて見るところから始め、過去の観測で答え合わせをし、自分のモデルで風を予測するところまで試せます。

## 最初はデモで試す

1. [Colabを開きます](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M4Th4/blob/feature/coastal-wind-colab-v1/projects/coastal-wind-chaos/notebooks/coastal_wind_forecast_lab.ipynb)。
2. Colabの「ランタイム」から「すべてのセルを実行」を選びます。初回は必要なコードとライブラリの準備を待ちます。
3. 操作画面で「デモで過去検証」を選びます。日時は空欄のままにします。
4. 「解析を実行」を押します。予測と観測の比較、誤差の表、グラフが表示されます。
5. 「結果ZIPをダウンロード」を押して結果を保存します。

最初のデモは、仮想の海辺で生成した3年分の合成データです。材木座・辻堂・三浦の実測ではありません。地点の設定を変えても、デモがその地点の実測に変わるわけではありません。

Google Driveへの接続は必須ではありません。「すべてのセルを実行」では操作画面を用意し、実際の解析はボタンを押して始めます。コードを編集しなくても使えます。

## 目的に合うモードを選ぶ

| モード | 必要なもの | できること |
| --- | --- | --- |
| デモで過去検証 | 追加データなし | 合成データで学習・予測・誤差解析を体験する |
| CSVで過去検証 | 気象庁の時別値CSV | 過去のある時点までの情報で、その後の風をどの程度予測できたか調べる |
| 最新予報の比較 | インターネット接続 | 選んだ地点のJMA・ECMWF予報を取得して並べる |
| 過去の気象予報の検証 | 観測CSV、予報の初期時刻 | 保存されている特定の計算回の予報を観測と照合する |
| 将来予測 | 学習に足りる期間の観測と直近の観測 | 利用できる最新観測まででモデルを学習し、その先を予測する |

最新予報を取得した直後は、未来の観測がないため答え合わせはできません。未評価や照合0件は正常な状態です。予報を保存し、対象時刻を過ぎてから観測をそろえて評価します。

## 地点の選び方

材木座は既存の気象予報を見る地点です。辻堂・三浦は、観測と比較できる地点として扱います。辻堂の観測で学習したモデルは辻堂の風を予測し、三浦のモデルは三浦の風を予測します。近隣観測所での精度を、材木座海岸そのものの精度とは解釈しません。

別の場所の予報を見るときは緯度・経度を指定します。別の観測所で学習するときは、その観測所のCSVを読み込みます。陸・海の指定は予報モデルが参照する格子の選び方です。同じモデルの陸側・海側を、独立した別モデルとして数えるものではありません。

## 自分の観測データを使う

1. 気象庁の[過去の気象データ・ダウンロード](https://www.data.jma.go.jp/risk/obsdl/index.php)を開きます。
2. 観測所を1地点選びます。データの種類を「時別値」にし、風速と風向を選びます。気温・気圧・日照も使う場合は、提供されている項目を追加します。
3. 品質情報と均質番号を含めてCSVを保存します。長期間で取得量の上限を超えるときは、年ごとに分けて保存します。
4. Colabで「CSVで過去検証」を選び、「CSV・保存データを選ぶ」からファイルを指定します。同じ観測所の複数年分はまとめて選べます。
5. 必要なら日時と入力項目を変え、「解析を実行」を押します。

複数の観測所を同じCSVにまとめたり、別地点の年を混ぜたりしないでください。再アップロードすると入力ファイルの選択は置き換わります。前の解析で選んだファイルが自動的に追加されることはありません。

入力CSVにない項目は作り足しません。欠測のため使えない行は除外理由を記録します。年代によって観測項目や測器の条件が変わるため、解析前に表示される期間・欠測状況も確かめます。

## 日時と期間を設定する

通常の画面に入力する日時は日本標準時（JST）です。「過去予報の初期時刻」だけはUTCで指定します。

| 設定 | 意味 |
| --- | --- |
| 学習開始 | 学習に使う観測の先頭 |
| 調整開始 | モデルの候補を比較する期間の先頭 |
| 最終評価開始 | 選んだモデルを採点する期間の先頭 |
| データ終了 | 解析に使う観測の末尾 |
| 将来予測の基準時刻 | この時刻までにある観測を使って、その先を予測する |

過去検証で日時を空欄にすると、データに応じた時間順の分割を使います。3年分なら、最初の1年で学習し、次の1年で設定を選び、最後の1年で評価する形が基本です。調整後は、最終評価より前のデータで学習し直します。

例えば「2023年で学習、2024年で調整、2025年で最終評価」とします。学習と評価の日付をランダムに混ぜることはしません。短い期間でも試せますが、夏だけの評価を一年中の性能と考えないようにします。

「日時をリセット」で日時欄を空に戻せます。「設定を初期化」は、モードや予測時間なども含めて初期値に戻します。

## 何時間先を予測するか

標準は1・3・6・12・24時間先です。36・48・72時間先も選べます。機械学習では予測する時間先ごとに直接予測するモデルを作り、未来の実観測を次々に入力して先へ進めることはしません。

既存の気象予報は24時間を基本にします。48・72時間は、選んだモデルと計算回にデータがある範囲だけを使います。表やグラフの空欄を架空の値で埋めることはありません。

将来予測にも学習用の観測が必要です。最低30日以上を目安とし、季節を含めて調べるときは1年以上の観測を用意します。直近数日だけの取得では、年単位のCSVの代わりにはなりません。欠測や入力の準備で使えない行があるため、30日ちょうどでも学習行が足りない場合があります。

将来予測では「最新入力観測時刻」と「予測対象時刻」を確かめます。1時間前までのCSVから作った予測は、現在の観測を入力した予測とは異なります。合成データや過去のCSVで将来予測を試す場合も、そのデータの末尾を基準とする実験です。

## 結果の読み方

### 時系列と散布図

時系列では、予測が風の強まりや弱まり、風向の変化を捉えたかを見ます。風速の散布図で観測と予測が同じなら、点は対角線の近くに並びます。強い風だけ外れる場合もあるため、全体の平均だけで判断しないことが大切です。

### 誤差の表

| 項目 | 読み方 |
| --- | --- |
| 風速MAE（m/s） | 風速を平均で何m/s外したか。小さいほどよい |
| 風速RMSE（m/s） | 大きく外した予測を強めに反映した誤差。小さいほどよい |
| 風速の偏り（m/s） | 「予測−観測」の平均。正なら強く、負なら弱く予測する傾向 |
| 風向MAE（度） | 円周上の短い側で測った角度差の平均。北の359°と1°は2°違い |
| 45°以内の割合（%） | 風向の外れが45°以内に収まった割合。大きいほどよい |
| ベクトルRMSE（m/s） | 風速と風向を合わせた風の成分の誤差 |
| 評価件数・除外件数 | 何件の答え合わせができ、何件を欠測などで使えなかったか |

静穏時は風向が定まらないため、風向の採点から外します。風がある観測に対して予測の向きが決まらなかった場合は、その予測だけを採点から落として成績をよく見せることはしません。詳しい定義は[解析方法](forecast-method.md)にまとめています。

### 単純な予測より改善したか

持続予報は「今と同じ風が続く」とする予測です。改善度が正なら、その基準より風速MAEが小さく、負なら大きいことを表します。0%は同程度、20%はMAEが2割小さいという意味です。基準の誤差が0のときは、割合としての改善度を計算できません。

95%区間は、日ごとのまとまりを保ってデータを取り直したときの改善度のばらつきです。区間が0をまたぐ場合は、改善の方向が安定しているとは言い切れません。評価できた日が1日だけの場合は、この区間を表示しません。この区間は、将来の風速が95%の確率で入る範囲ではありません。

月・時刻・風向・風速帯ごとの図では「夏の昼間」「北寄りの強風」などの条件を比べられます。件数の少ない条件は偶然の影響も大きいため、必ず件数と一緒に読みます。

## 結果を保存して使い直す

結果ZIPには、予測・観測との照合結果、集計表、解析条件、図をまとめます。観測データを使った解析では、読み込んだ観測も保存します。ファイルの意味は[出力形式](forecast-format.md)を参照してください。

元の観測CSVも手元に残しておくと、入力項目や予測時間を変えて再解析できます。Google Driveは任意の保存先です。Colabのセッションを終了すると、セッション内だけに置いたデータや結果は失われるため、必要なZIPはダウンロードしておきます。

## うまく動かないとき

| 表示・状況 | 確かめること |
| --- | --- |
| 学習データが足りない | 学習開始と調整開始の間隔、読み込んだ年数、欠測を確認する。まず日時をリセットして試す |
| CSVを読み込めない | 気象庁の時別値か、風速・風向を含むか、1地点かを確認する |
| 最新予報の誤差が空欄 | 未来の観測がない状態では正常。予報の表示と精度評価を区別する |
| 過去予報を取得できない | モデルの保存開始日、初期時刻、インターネット接続を確認する |
| 将来予測の入力が足りない | 基準時刻の直前24時間程度に必要な観測があるか確認する |
| グラフが英語 | 日本語フォントが見つからないときの代替表示。軸の単位と指標は同じ |

このラボでは、条件を変える前に同じデータで基準となる結果を保存すると比較しやすくなります。まずは予測する時間先を一つだけ変え、何が変わったか確かめてみてください。
