# 学生制作の解析コード

提出Notebookの音源比較セルから、関数部分を取り出して保存しています。氏名や学籍番号、実行出力、授業の共通演習セルは含めていません。先頭のNotebook用インストール行はコメントに変え、実行例のURL一覧は外しています。

このコードは制作の出発点を確認するための参照資料です。音声波形の100–8000 Hzを対数直線で近似した値は、今回の音量の時間変動の解析とは異なります。新しい結果とのランキングには混ぜません。

実際に使う場合は、公開版のNotebookと `vocal_lab` の処理を使ってください。歌声分離、区間切り出し、エラー表示、解析方法の説明を追加しています。
