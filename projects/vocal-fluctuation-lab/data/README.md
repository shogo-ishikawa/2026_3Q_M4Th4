# 比較データの作り方

このフォルダには音源を含めていません。新しい解析方法で実測したアーティストの比較データベースは、初めは空です。アーティスト名に架空の測定値を付けることはしていません。

`reference_catalogue.json` は学生の調査資料に登場した再解析候補の一覧です。曲名は解析画面に記載されていたもので、動画の題名や内容と照合した結果ではありません。使う音源と区間は自分で確認してください。動画が取得できない場合は、利用できる音源ファイルをアップロードします。開始・終了秒が空欄なのは、元の比較で使った区間を確定できないためです。

`student_legacy_results.json` は提出画面の数値の記録です。これは歌声波形の100–8000 Hzの傾きであり、配布版が測る時間方向の音量ゆらぎとは異なります。新しい比較順位には使いません。

## 実測値を登録する

1. 比較用の曲を、調べる曲と同じ解析設定で処理します。
2. 抽出した歌声を聴き、歌が入っていることと伴奏の残り方を確認します。
3. 比較に使える品質の結果に、アーティスト名と曲名を付けて登録します。
4. 特徴量のデータベースをJSONで保存します。別の日や別の端末では、そのJSONを読み込みます。

例では、Notebookの解析結果を `result`、データベースを `database` とします。

```python
from vocal_lab.reference_db import empty_database, add_reference, save_database

database = empty_database()
database = add_reference(database, result, artist="比較するアーティスト", track="曲名")
save_database(database, "artist_references.json")
```

音源は利用できるものを用意してください。保存されるのは特徴量、解析区間、音源の識別用ハッシュ、アーティスト名などです。音声データは含みません。出典やメモに個人情報を書かず、他人の音声や比較データを共有する場合は共有できる範囲を確認します。

## 候補一覧をまとめて実測する

Colabの任意の比較DB作成セル、または次のコマンドで候補一覧を順に解析できます。実行する前に、動画と曲名が対応することと、指定した区間に歌が入っていることを確認してください。初期値は各曲の40〜130秒です。候補JSONに個別の開始・終了秒を書いた場合は、そちらを使います。

```sh
python -m vocal_lab.build_references \
  --catalogue data/reference_catalogue.json \
  --output outputs/reference-build \
  --start 40 --end 130 --device auto
```

区間は通常の解析と同じ10〜600秒で指定できます。比較に使うには、前処理後にも60秒以上の歌声区間が必要です。取得できた曲でも、長さや変動の品質が足りなければ比較DBには加えません。失敗は実行記録に残り、先に保存した実測値は消えません。YouTubeから取得できない場合は、利用できる音源をアップロードして登録してください。

### 無音処理の設定をそろえる

v1.1.0からは、抽出した歌声の前後にある無音を既定で除きます。曲の途中の間奏や息継ぎは時間軸に残します。途中の長い無音まで除く設定もありますが、離れた箇所をつなぐため時間軸が変わります。その設定で得たゆらぎは、無音を残した結果と分けて比較します。

Pythonからは、通常の解析と同じ `silence_config` を渡します。

```python
from vocal_lab.build_references import build_reference_catalogue

built = build_reference_catalogue(
    "data/reference_catalogue.json", "outputs/reference-build",
    start_seconds=40, end_seconds=130,
    silence_config={"trim_edges": True, "remove_internal": False},
)
database = built["database"]
```

コマンドでは `--no-trim-edges` で前後の無音を残し、`--remove-internal-silence` で途中の長い無音も除く設定にできます。無音とみなす相対レベルを変える場合は `--silence-threshold-db` を指定します。比較する音源同士で設定をそろえてください。

同じ出力フォルダで作成を再開するときは、曲、出典、指定区間、解析設定、無音処理の設定、Demucsの版が同じ実測値だけを省略します。v1.0.0の無音を除かない結果や、しきい値を変更する前の結果は残したまま再解析します。新旧の結果は署名で区別され、同じ条件として順位に混ざりません。

## 「近い」の意味

比較するのは音量包絡の4特徴量です。傾きは0.5、変動係数は0.5、低周波側の割合は0.25、スペクトル平坦度は0.25をそれぞれの尺度に使い、尺度で割った差の二乗平均平方根を距離とします。この尺度は教育用ツールの固定設定であり、歌手識別の精度を検証して得た値ではありません。

まず同じ曲の複数区間を平均し、次に曲ごとに同じ重みでアーティストの平均を求めます。一曲から多くの区間を登録しても、その曲だけが強く結果を左右しないためです。解析条件、無音処理を含む歌声の前処理、モデルの版が異なる実測値は混ぜません。同じ音源・区間は自分自身との比較から除きます。

距離が小さいほど、今回測った音量の揺れ方が近いという意味です。声質、本人、歌唱力の一致率ではありません。一曲しかない場合は「1曲の参考値」と表示します。曲、歌う場所、録音や音量調整によっても値は変わるので、複数曲で確かめてください。
