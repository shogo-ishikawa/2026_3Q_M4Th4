01 / 音と波

聞こえる音を、
グラフにしてみる。

空気中の音は、圧力の変化が伝わる現象です。
マイクはその変化を、時間に沿った信号として記録します。

横は時間、縦は圧力の変化。

波形は、ある場所で圧力が高くなったり低くなったりする様子を並べたグラフです。横軸を右へ進むと、時間が進みます。

空気は音が進む向きに押されたり戻ったりします。波形の上下は、空気が上下へ動く軌跡ではありません。

A

振幅：振れ幅の大きさ

同じ高さの単純な音なら、振幅が大きいほど強い音になります。

f

周波数：1秒間の繰り返しの回数

単位はHz（ヘルツ）。440 Hzなら、1秒間に440回の繰り返しです。単純な音では、周波数が高いほど高い音に聞こえます。

振れ幅と周波数を変えてみよう

単純な正弦波

周波数を変えると、同じ時間に入る波の数が変わります。

再生ボタンを押したときだけ、小さな合成音が鳴ります。

聞こえる大きさは振幅だけでなく、周波数や耳の感度、再生機器にも左右されます。この図の相対値は、実際の音圧や聞こえ方の点数ではありません。

02 / スペクトル

複雑な波を、
「何が混ざっているか」で見る。

波形は「時間とともにどう変わるか」。
スペクトルは「どの周波数の成分が、どれくらいあるか」です。

声や楽器の波形には、いくつもの周波数の成分が重なっています。下の例では220 Hzの波に440 Hzの波を足します。440 Hzの成分を増やすと、波形の形とスペクトルの棒が一緒に変わります。

2つの波を足してみよう

式から作った理想的な例

足し合わせた正弦波の成分を、式から表示しています。実際の音源では、フーリエ変換という計算で周波数ごとの成分を調べます。

パワーは「振幅の二乗」に関係します。

この棒は、各成分の1周期の平均二乗を示しています。正弦波の振幅がAなら、パワーはA²/2です。振幅を2倍にすると、パワーは4倍になります。

音源の解析では、周波数1 Hzあたりのパワーを表すパワースペクトル密度（PSD）も使います。1/fゆらぎでは、このPSDの形を見ます。

ここまでのポイント

同じ波を、時間の目と周波数の目で見ています。

スペクトルは別の音ではなく、元の信号の成分を見やすくした表し方です。

03 / 1/fゆらぎ

音の高さから、
音量の変わり方へ。

歌声は細かく振動しながら、
フレーズに合わせて大きくなったり小さくなったりします。

440 Hz

音そのものの細かな振動

1秒間に440回の繰り返し。音の高さに関係する周波数です。

≠
0.5 Hz

音量が変化する速さ

2秒かけて大きくなり、小さくなる繰り返し。ゆらぎの周波数です。

細かな振動を包む、ゆっくりした線。

細かな振動の大きさをまとめると、音量の強弱の変化を取り出せます。このアプリではRMS（平均二乗平方根）をもとに、波形を二乗してなめらかにした後で平方根を取ります。正負の値が打ち消し合うことなく、強弱を表す線を作れます。この線を包絡（ほうらく）と呼びます。

RMSは振幅の強弱の目安です。人が感じる音の大きさを、そのまま測る指標ではありません。

もう少し詳しく：現在の包絡の作り方

現行版では、波形の二乗に低域通過処理を適用してから平方根を取ります。20 Hzまでの音量変化を調べるため、毎秒200点の包絡を作ります。ステレオでは左右を二乗してから平均し、左右の波が打ち消し合う影響を避けます。詳しい解析方法

1/fは、いろいろな速さの変動の割合。

音量の時間変化にも、スペクトルを求められます。ゆっくりした変化と速い変化が、どのくらい含まれるかを調べるためです。

ある周波数範囲で、変動のPSDが周波数fに反比例するとき、その範囲に1/fゆらぎの性質があると呼びます。周波数が2倍になるとPSDは半分、10倍になると10分の1です。

P(f) ∝ 1/f = f−1

横軸と縦軸を対数にすると、この関係は傾き−1の直線になります。対数の軸は、同じ差ではなく「2倍」「10倍」といった比で目盛りを読む軸です。

周波数を、変化にかかる時間で読む。

ゆらぎの周波数fに対応する時間の目安は1/fです。低い周波数ほど、ゆっくりした変化を表します。実際の歌声には、いろいろな速さの変動が混ざっています。

Colabの自動モードは、音源の長さに合わせて低周波側の範囲と計算に使う時間窓を決めます。固定モードは0.2〜20 Hzを希望範囲とし、曲どうしの条件をそろえるときに使います。どちらも、実際に使えた帯域を結果で確認します。

高周波側は、この実装で調べられる20 Hzまでを使い、5 Hzまでの結果も並べます。範囲を広げると必ず1/fから遠ざかるとは限りません。同じ歌声で、範囲を変えたときの傾きと当てはまりを比べます。

曲全体とサビでは、どちらを使う？

長い音源は、遅い変動を調べたり計算を平均したりする材料を増やせます。一方、全曲にはイントロ、サビ、間奏などの違いも混ざります。全体の結果に加え、同じ長さの複数区間を同じ設定で調べると、場所による違いを確かめられます。録音を長くするだけで、高周波側の上限が広がるわけではありません。

「傾きが−1」だけで決めない。

有限の長さのデータでは、傾きはぴったり−1にはなりません。調べる区間や周波数範囲、直線への当てはまり、時間帯による違いを一緒に確かめます。R²は直線への当てはまりの目安で、1に近いほど点が直線に沿います。

歌声の場合は、伴奏の残り方や間奏、音量調整も結果に入ります。1/fに近いという結果は、癒やしや歌の上手さの証明にはなりません。

抽出した歌声には、コーラスや多重録音、リバーブも含まれ得ます。ここで調べるのは、その録音に含まれるボーカル全体の変動です。歌い手本人だけに固有の性質とは限りません。

もう少し詳しく：1/fは何を均等に含む？

理想的な1/fのPSDを持つ範囲では、1〜2 Hzと2〜4 Hzのように、周波数が2倍になる幅ごとの合計パワーが等しくなります。周波数1 Hzあたりのパワーが、どこでも同じという意味ではありません。

  1. ColabでWAVを取り込み、「今回の音源」にファイル名と大きさが出たことを確認します。
  2. 「歌声だけの音源です（分離を省略）」をオンにします。元音源から抽出し直す必要はありません。
