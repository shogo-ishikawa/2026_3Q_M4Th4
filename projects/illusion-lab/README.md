# Illusion Lab — 錯視の実験室

v1.1.0。18種類の錯視を生成して、見え方と図の値を比べるブラウザアプリです。補助線・周囲の表示・重ね合わせで仕組みを確かめられます。

[実験室を開く](https://shogo-ishikawa.github.io/2026_3Q_M4Th4/illusion-lab/) ／ [遊び方](web/guide.html)

## まず試す

1. 実験室で錯視を選びます。最初はミュラー・リヤー錯視がおすすめです。
2. AとBのどちらが長く見えるかを考えます。
3. 答え合わせを開きます。補助線と数値を確認してください。
4. 周りの模様を薄くしたり、対象を重ねたりして比べます。
5. 新しい図を生成して配置や強さを変えます。

長さや直径は図の座標上の単位です。傾きは度、色は図に指定したRGB値などで比べます。画面の大きさが変わっても図形同士の比は保たれます。

## 錯視を詳しく知る

答え合わせの「この錯視を詳しく知る」から、見どころ・見え方に影響する要素・確かめ方・追加の実験を読めます。クイズの回答後と結果の見直しでも同じ解説を開けます。使い方ページには全18種類の解説をまとめています。

## ランダムクイズ

難易度・問題数・出題する分野を選んで始めます。長さ・大きさ・傾き・つながり・色などの問題に答え、回答後に図を操作して確かめられます。

同じ寸法の図と異なる寸法の図を混ぜて出題します。セット番号をそろえると同じ問題を再現できます。友人と同じ条件で遊んだり、結果の見直しから苦手だった図へ戻ったりできます。

## 収録する錯視

| 分野 | 種類 |
| --- | --- |
| 長さ | ミュラー・リヤー、ポンゾ、垂直・水平、オッペル・クント |
| 大きさ | エビングハウス、デルブーフ、ジャストロー |
| 方向とつながり | ツェルナー、カフェウォール、ポッゲンドルフ、ヘリング、ヴント |
| 明るさと色 | 明るさの同時対比、ホワイト、色の同時対比 |
| 図形の見え方 | ヘルマン格子、カニッツァの三角形、フレーザーの渦巻き |

錯視の見え方は人や画面によって変わります。答え合わせでは実際に描いた座標・寸法・色の値を確認します。

## 図や結果を持ち出す

SVGは拡大しても図形の輪郭を保てる画像形式です。PNGはスライドや文書へ貼り付けやすい画像形式です。クイズの結果はCSVで保存できます。

出題条件の共有リンクを使うと、同じ問題セットを別のブラウザでも開けます。

## パソコンで起動する

ZIPを展開すると `v1.1.0` フォルダができます。そのフォルダでターミナルを開きます。

Windows：

```sh
py run.py
```

macOS・Linux：

```sh
python3 run.py
```

ブラウザが開かない場合は `http://127.0.0.1:8000/` を開いてください。終了はターミナルで `Ctrl+C` です。Python 3の標準ライブラリで動きます。

配置例：`/Users/shogo/Dropbox/share_data/open_material/misc/apps/IllusionLab/v1.1.0`

## コードを調べる

| ファイル | 内容 |
| --- | --- |
| `web/core.js` | 錯視の条件、寸法、正解、ランダム出題 |
| `web/renderer.js` | SVG画像と答え合わせの描画 |
| `web/app.js` | 操作画面、クイズ、画像と結果の保存 |
| `web/guide.html` | 遊び方と各錯視の詳しい解説 |
| `web/lessons.js` | 18種類の見どころ、背景、操作手順、追加の実験 |

Node.jsがある場合は次のコマンドで確認できます。

```sh
node --test tests/*.test.mjs
```

GitHubでは `projects/illusion-lab/` で管理します。フォルダ内で次のコマンドを実行するとHTTPSでアップロードできます。

```sh
bash sync_to_github.sh
```

GitHubへの書き込み権限とGitの認証設定が必要です。GitHub Actionsで確認後にPagesへ反映します。
