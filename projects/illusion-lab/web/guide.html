01 / GET STARTED

まず一つの錯視を試そう

  1. 実験室で錯視を選びます。最初はミュラー・リヤー錯視がおすすめです。
  2. AとBを見比べ、どちらが長く見えるかを考えます。
  3. 答え合わせを開き、補助線と数値を見ます。
  4. 周りの模様を薄くしたり、対象を重ねたりして比べます。

新しい図を生成すると配置や条件が変わります。難易度も切り替え、周りの形が見え方へ与える影響を探してみてください。

02 / REVEAL THE GEOMETRY

三つの方法で確かめる

01

補助線と数値

端点や中心、傾きの基準を表示します。長さ・直径は図の座標上の単位、角度は度、色は図に指定したRGB値などで比べます。

02

周りの模様を隠す

対象を残して周りの線や円を薄くします。周囲がある場合とない場合を行き来し、見え方の違いを確かめます。

03

重ねて比べる

線や円の位置をそろえて比較します。縦線と横線の長さを比べるときは向きをそろえます。つながりの問題では斜線を延長して確かめます。

錯視の見え方は人や画面によって変わります。答え合わせでは、図に描いた座標・寸法・色の値を確認します。

03 / RANDOM CHALLENGE

何度でも遊べるランダムクイズ

  1. クイズへ切り替えます。
  2. 難易度・問題数・出題する分野を選びます。
  3. 図を見て答えを一つ選びます。
  4. 正解と解説を読み、図を操作して確かめます。
  5. 最後に結果を見直し、同じセットへ再挑戦するか新しい問題を始めます。

実際に同じ寸法の図と、異なる寸法の図を混ぜています。見慣れた錯視でも図をよく見て選びましょう。

同じセット番号と出題条件なら同じ問題を再現できます。友人と条件をそろえて遊ぶこともできます。

04 / THE COLLECTION

18種類の錯視

何を比べる？収録する錯視
長さミュラー・リヤー、ポンゾ、垂直・水平、オッペル・クント
大きさエビングハウス、デルブーフ、ジャストロー
方向とつながりツェルナー、カフェウォール、ポッゲンドルフ、ヘリング、ヴント
明るさと色明るさの同時対比、ホワイト、色の同時対比
図形の見え方ヘルマン格子、カニッツァの三角形、フレーザーの渦巻き

線や円の比較に加え、描かれていない輪郭が見える図や、同心円が渦巻きに見える図も観察できます。

05 / SAVE & SHARE

図や問題を持ち出す

SVG画像

図形の輪郭を保ったまま拡大できる形式です。図の構造を調べたり、資料の図版として使ったりできます。

PNG画像とCSV

PNGはスライドや文書へ貼り付けやすい画像です。クイズの結果はCSVで保存して見比べられます。

同じ問題を共有

出題条件のリンクを共有すると同じ問題セットを開けます。難易度と問題数もそろえて再挑戦できます。

ダウンロード版を起動する

ZIPを展開し、v1.1.0 フォルダでWindowsは py run.py、macOS・Linuxは python3 run.py を実行します。ブラウザが開かない場合は http://127.0.0.1:8000/ を開いてください。
