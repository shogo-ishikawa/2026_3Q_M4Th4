A LETTER THROUGH THE NIGHT

灯りの配達人の遊び方

手紙をかばんに入れて夜の道へ。灯の芯を集め、消えた灯台にもう一度灯りをともす旅です。

はじめる進み方操作武器と守り方寄り道セーブ4分デモ
01 / START

最初の配達へ出かけよう

  1. 「配達をはじめる」を押します。
  2. 最初の武器を選びます。迷ったら夜番のランタンがおすすめです。
  3. 会話を読み、E か画面のボタンで進めます。
  4. 右へ歩きながら足場を跳び、金色のひし形を探しましょう。

人や街灯に近づくと調べる案内が出ます。E を押すと話したり調べたりできます。

BEFORE YOU PLAY

すぐに遊べます

パソコンのキーボード操作がおすすめです。タッチ画面では画面内のボタンも使えます。

ダウンロードした場合はZIPを展開し、Lantern_Post.html をブラウザで開きます。インストールやサーバーの起動は不要です。

右上の「中文」「日本語」で言語を切り替えられます。音はスピーカーでオンにできます。

02 / THE DELIVERY

各章で3つの目標をそろえる

町から森へ。そして灯台へ。3つの章を進み、最後に灯台守のアオへ手紙を届けます。

✦灯の芯を1つ取る

高い足場にある金色のひし形を探します。

◇中継灯を2つともす

近くで E を押すか攻撃を当てます。

⚔ボスを2体倒す

攻撃前の構えを見て、避けた後に反撃します。

画面上部に芯・中継灯・ボスの進行が表示されます。そろったら右端へ進み、案内に従って次の章へ向かいましょう。

03 / CONTROLS

操作一覧

キーできること
←→ / AD左右へ移動します。
Space / ↑ / Wジャンプします。敵の上から着地すると踏みつけ攻撃になります。
↓ / S通り抜けられる足場から下へ降ります。
X選んでいる武器で攻撃します。
Q4種類の武器を順に切り替えます。
Z / Shift気力を使って回避します。短い間攻撃をすり抜けられます。
C 長押し向いている側からの攻撃をガードします。
Iお守りの装備画面を開きます。
E話す・調べる・中継灯をともす・会話を進める操作です。
数字キー会話の返事や消印を選びます。
Esc / P一時停止・再開します。
J配達手帳で依頼やボスのヒントを確認します。
04 / LIGHT & DEFENCE

4つの武器を使い分けよう

どの武器でも本編を進められます。途中でも Q で自由に切り替えられます。

夜番のランタン

安定した連射。初めての配達におすすめ。

星糸の弓

遠くまで貫く高威力の光。発射はゆっくり。

振り子の杖

近距離への重い一撃。複数の敵を押し返す。

風鈴の扇

三方向に光を放ち、空中の敵を狙いやすい。

避ける・守る・反撃する

ボスが光ったり構えたりしたら攻撃の合図です。Z で回避するか、敵の方を向いて C でガードし、攻撃が終わったところを狙いましょう。気力は時間とともに回復します。

攻撃が当たる直前に C を押すとジャストガードになります。反撃の機会が生まれ、飛んできた光弾を反射できます。落下・地面の霧・蒸気はガードで防げません。

灯りが尽きたり落下したりすると街灯からやり直せます。取得物と仕掛けの進行は残ります。Esc のメニューから街灯や寄り道の入口へ戻ることもできます。

05 / A SMALL DETOUR

寄り道で出会う人と贈り物

各章にはそれぞれ寄り道があります。近くの人に話しかけて依頼を受け、奥の部屋の仕掛けに挑みましょう。くつ・レンズ・封ろうなどの助けが手に入り、途中や結末の会話も変わります。

消印を集める

消印には攻撃を速くしたり灯りの上限を増やしたりする効果があります。選んだ消印は消印帳に集まります。別の配達でも収集を楽しめます。

お守りを身につける

I で入手済みのお守りを1つ装備できます。灯りを増やすものや回避を助けるものなど、遊び方に合わせて選びましょう。

寄り道やお守りを使わずに本編をクリアすることもできます。章を出た後の寄り道は次の配達で訪れましょう。探索や会話を楽しんだ本編の目安は約20分です。

06 / CONTINUE YOUR JOURNEY

配達の続きを残す

通常の配達はブラウザへ自動セーブされます。中断するときは Esc を押し、「記録してタイトルへ」を選びます。

次回は同じブラウザで同じファイルまたは同じ公開ページを開き、「前回のつづき」を押してください。

新しく出発する場合は「配達をはじめる」から「新しい配達へ」を選びます。途中の記録は新しくなり、消印帳は引き継がれます。

07 / FOUR-MINUTE DEMO

まず4分間で眺めてみる

  1. タイトルの「授業デモ」を押します。
  2. 「▶ 自動デモを開始 · 4:00」を選びます。
  3. 物語・武器・回避・寄り道・ボス戦・結末を自動で紹介します。

6体のボスから毎回3体が登場します。4:00は再生している時間です。一時停止中や別の画面に切り替えている間は時計も止まります。戻ったら「つづける」を押します。

本編のセーブや消印帳はデモで書き換わりません。「自分でデモを遊ぶ（時間制限なし）」ではデモ用の固定ルートを自分で操作できます。

WHEN YOU NEED A HAND

困ったときは

こんなとき試すこと
動かない会話やメニューを閉じ、ゲーム画面をクリックします。
先へ進めない画面上部の芯・中継灯・ボスの進行を見ます。J で手帳も確認できます。
途中でやり直したいEsc →「街灯・寄り道の入口に戻る」を選びます。
音が出ない右上のスピーカーを押します。
続きが見つからない前回と同じブラウザで同じファイルの場所や公開ページを開きます。

準備ができたら、灯りを持って出かけましょう。
