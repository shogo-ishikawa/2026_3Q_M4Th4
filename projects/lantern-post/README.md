# 灯りの配達人 — Lantern Post

v3.0.0

嵐で消えた灯台へ手紙を届ける2Dアクションゲームです。見習い配達人のミオとなり、町・森・灯台へと続く3つの章を旅します。

## 開いて遊ぶ

1. ZIPを展開します。`v3.0.0` フォルダができます。
2. `Lantern_Post.html` をダブルクリックしてブラウザで開きます。
3. 「配達をはじめる」を押します。
4. 最初の武器を選び、画面の会話を読み進めます。初めてなら「夜番のランタン」がおすすめです。

インストールやサーバーの起動は不要です。ダウンロード後はオフラインで遊べます。Chrome・Edge・Firefoxなどのブラウザとパソコンのキーボードでの操作がおすすめです。

最初は日本語で表示されます。右上の「中文」「日本語」で言語を切り替えられます。

詳しい操作案内は [guide.html](guide.html) を開いてください。

## 最初は何をする？

右へ進みながら足場に飛び乗り、金色のひし形を探します。これが灯台をともす「灯の芯」です。人や街灯の近くで `E` を押すと話したり調べたりできます。

各章では次の3つをそろえて先へ進みます。

- 金色の灯の芯を1つ取る
- 中継灯を2つともす
- ボスを2体倒す

中継灯は近くで `E` を押すか攻撃を当てると点灯します。条件を満たしたら右端へ向かい、画面の案内に従って次の章へ進みましょう。最後は灯台守のアオに手紙を届けます。

## 操作

| キー | 操作 |
| --- | --- |
| `←` `→` / `A` `D` | 左右へ移動 |
| `Space` / `↑` / `W` | ジャンプ。敵の上から着地すると踏みつけ |
| `↓` / `S` | 通り抜けられる足場から下へ降りる |
| `X` | 選んでいる武器で攻撃 |
| `Q` | 4種類の武器を順に切り替える |
| `Z` / `Shift` | 回避。気力を使い、短い間攻撃をすり抜ける |
| `C` 長押し | 向いている側からの攻撃をガード |
| `I` | お守りの装備画面を開く |
| `E` | 話す・調べる・中継灯をともす・会話を進める |
| 数字キー | 会話の返事や消印を選ぶ |
| `Esc` / `P` | 一時停止・再開 |
| `J` | 配達手帳を開く |

タッチ画面では画面内の操作ボタンを使えます。サウンドは右上のスピーカーで切り替えます。

## 武器と守り方

| 武器 | 特徴 |
| --- | --- |
| 夜番のランタン | 安定した連射。最初の配達に向く |
| 星糸の弓 | 遠くまで貫く高威力の光。発射はゆっくり |
| 振り子の杖 | 近距離への重い一撃。複数の敵を押し返す |
| 風鈴の扇 | 三方向に光を放つ。空中の敵を狙いやすい |

武器は途中でも `Q` で切り替えられます。ボスが攻撃する前の光や構えを見て、回避かガードの後に反撃しましょう。

攻撃が当たる直前に `C` を押すとジャストガードになります。反撃の機会が生まれ、遠距離の光弾は反射できます。落下・地面の霧・蒸気はガードで防げません。気力は時間とともに回復します。

灯りが尽きたり落下したりすると街灯からやり直せます。取得物と仕掛けの進行は残ります。一時停止メニューの「街灯・寄り道の入口に戻る」でも戻れます。

## 寄り道を楽しむ

3つの章にはそれぞれ寄り道があります。人に話しかけて依頼を受け、奥の部屋の仕掛けに挑みます。くつ・レンズ・封ろうなどの助けを得られ、旅の途中や結末の会話も変わります。

消印は光の攻撃や灯りの上限などを強化します。手に入れた消印は消印帳へ集まります。お守りは `I` で開き、入手済みのものを1つ装備できます。

寄り道やお守りを使わずに本編をクリアすることもできます。章を出た後の寄り道は次の配達で訪れましょう。本編は探索や会話を楽しんで約20分が目安です。

## 続きから遊ぶ

通常の配達はブラウザへ自動セーブされます。中断するときは `Esc` を押し、「記録してタイトルへ」を選ぶと進行を残せます。

次回は同じブラウザで同じファイルまたは同じ公開ページを開き、タイトルの「前回のつづき」を押します。「新しい配達へ」を選ぶと途中の進行は新しくなり、消印帳は引き継がれます。

## 4分間の授業デモ

タイトルの「授業デモ」から「▶ 自動デモを開始 · 4:00」を選びます。物語・基本操作・4種類の武器・寄り道・ボス戦・結末を自動で紹介します。6体のボスから毎回3体が選ばれます。

4:00は実際に再生している時間です。一時停止中や別の画面に切り替えている間は時計も止まります。戻ったら「つづける」を押してください。本編のセーブや消印帳はデモで書き換わりません。

「自分でデモを遊ぶ（時間制限なし）」ならデモ用の固定ルートを自分で操作できます。

## 困ったとき

| 状況 | 操作 |
| --- | --- |
| キーを押しても動かない | 会話やメニューを閉じ、ゲーム画面をクリックする |
| 次へ進めない | 画面上部で芯・中継灯・ボスの進行を確認する。`J` で配達手帳も開ける |
| 途中でやり直したい | `Esc` →「街灯・寄り道の入口に戻る」 |
| 音が出ない | 右上のスピーカーを押す |
| 続きが見つからない | 前回と同じブラウザ・同じファイルの場所や公開ページで開く |

## コードを編集する

ゲームの描画・物語・操作は `Lantern_Post.html` にまとまっています。テキストエディターで開き、変更を保存してからブラウザを再読み込みします。

配置例：`/Users/shogo/Dropbox/share_data/open_material/misc/apps/LanternPost/v3.0.0`

Node.jsがある場合は次のコマンドで動作を確認できます。

```sh
node --test tests/*.test.mjs
```

GitHub上のコードは `projects/lantern-post/` で管理します。フォルダ内で次のコマンドを実行するとHTTPSでアップロードできます。

```sh
bash sync_to_github.sh
```

GitHubへの書き込み権限とGitの認証設定が必要です。更新後はGitHub Actionsで確認し、Pagesへ反映します。
