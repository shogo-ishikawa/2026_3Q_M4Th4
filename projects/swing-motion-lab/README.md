# Motion Analysis Lab

動画から身体の動きをとらえ、映像とグラフを一緒に見比べるアプリです。スイング、スクワット、腕の曲げ伸ばしなどを、肩・腰の向きや関節の角度から調べます。

[アプリを開く](https://shogo-ishikawa.github.io/2026_3Q_M4Th4/swing-motion-lab/)

## 最初の操作

1. 「デモで試す」から動作を選んで「開く」を押し、再生ボタンや時刻のバーを動かします。
2. 調べる量を切り替え、映像上の線と角度・角速度のグラフを見比べます。
3. 自分の動画を使うときは「ファイルから開く」でファイルを選ぶか、「URLから開く」に動画のURLを入力します。
4. 開始・終了秒を指定し、解析する人物の全身が入るように範囲を囲みます。
5. AIによる解析を実行し、関節の位置をコマ送りで確認します。
6. 点を修正したい時刻では、手動指定のボタンを選んで映像上をクリックし、座標を保存します。
7. CSVで数値を保存します。後から条件を変えたい場合は座標JSONも保存します。

## 動画を読み込む

### パソコンやスマートフォンのファイル

動画ファイルを選ぶボタンからMP4・WebMなどを読み込みます。ブラウザで再生できるコーデックの動画を使用します。短い動作を含む区間から始めると、姿勢の検出結果を確認しやすくなります。

### 動画ファイルのURL

MP4・WebMなどの動画ファイルへのHTTP(S)リンクを指定します。配信元が外部サイトからの読み込みを許可している動画を利用できます。HTTPSのページではHTTPSのURLを指定します。

YouTubeの視聴ページは動画ファイルへのリンクとは形式が異なります。その場合は手元の動画ファイルを選びます。

## 調べる量

| 選択する量 | 計算に使う点 | 読み方 |
| --- | --- | --- |
| 肩・腰の向き | 左右の肩、左右の腰 | 画像の右向きが0度。反時計回りが正 |
| 肘の角度 | 肩・肘・手首 | 肘が伸びるほど180度に近づく |
| 膝の角度 | 腰・膝・足首 | 膝が伸びるほど180度に近づく |
| 体幹の傾き | 肩の中点、腰の中点 | 直立が0度。画像の右へ傾く向きが正 |
| 角速度 | 選んだ角度と時刻 | 1秒当たりの角度変化。単位は度/秒 |

角度は画像の平面上で計算します。動画同士を比較するときは、撮影方向とスロー倍率をそろえます。肘や膝の曲がりを調べるときは、動作を横から撮ると関節の位置関係を捉えやすくなります。

肩と腰を結ぶ線は180度で同じ向きになります。ちょうど90度変わった隣接時点は回転方向を決められないため、区間を分けます。関節角は3点から求める0〜180度の角度です。

## 見やすくする設定

- **解析する頻度**：1秒に調べる時点の数です。まず15点で試し、速い動作では増やします。元動画のFPS以下を目安にします。
- **スロー倍率**：4倍スローなら4を選ぶと実時間へ換算します。角速度も4倍になります。
- **点の信頼度**：しきい値を上げると、確かな点を使う範囲に絞れます。
- **最小の線の長さ**：短すぎて向きが不安定な線を除きます。肘・膝では両側の線を確認します。
- **平滑化**：近くの連続した時点に直線を当てはめ、細かな揺れを抑えます。窓を変えて結果への影響を比べられます。

隠れた関節や信頼度の低い点は空欄になります。欠測の前後をつなげて角速度を計算しません。手動で修正するときは、その時刻のほかの点を残したまま、必要な位置を指定できます。

## 保存して再解析する

CSVには各時刻の角度・角速度・信頼度・元の関節座標を保存します。座標JSONには12点の座標と解析条件を保存します。JSONを読み込むと、動画がなくても調べる量・信頼度・平滑化・時間換算を変えられます。v1.0.0で保存した肩と腰のJSONも読み込めます。

## ローカルで開く

配布ZIPを展開すると `v1.1.0` フォルダができます。`web/index.html` をブラウザで開くと、デモと座標データを利用できます。自動推定では初回に姿勢推定ライブラリとモデルを取得します。

配置例：`/Users/shogo/Dropbox/share_data/open_material/misc/apps/MotionAnalysisLab/v1.1.0`

ローカルでの変更をGitHubへ反映するときは、このフォルダで `bash sync_to_github.sh` を実行します。HTTPSで書き込める認証を設定したGitを使用します。

## 開発と確認

```sh
node --test tests/*.test.js
```

ソースはクラスの[GitHubリポジトリ](https://github.com/shogo-ishikawa/2026_3Q_M4Th4)の `projects/swing-motion-lab/` で管理します。Pagesと配布ZIPはリポジトリ全体の `scripts/build_public_site.py` から生成します。

自動推定はMediaPipe Pose Landmarker Lite（tasks-vision 1.2.3）を使用し、WebGLを使えない環境ではMoveNet Lightning（TensorFlow.js 4.22.0、pose-detection 2.1.3）によるCPU処理へ切り替えます。

- [MediaPipe Pose Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker?tab=Web)
- [TensorFlow.jsの姿勢推定](https://github.com/tensorflow/tfjs-models/tree/master/pose-detection)
- [動画の外部読み込みとcrossOrigin](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/crossOrigin)
