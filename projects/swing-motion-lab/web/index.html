HOW TO USE

映像から、動きの違いへ。

解析の流れと、数字の読み方を確認しよう。

1. まずデモを動かす

時刻のバーを動かすと、肩と腰の線、角度、グラフ上の位置が一緒に変わります。肩が先に動く瞬間と、腰が動き始める瞬間を比べてみましょう。

2. 自分の動画を解析する

「動画を開く」でファイルを選び、開始・終了秒を指定します。「打者の範囲を囲む」で全身の動きが入るように囲み、「AIで肩・腰を解析」を押します。投手や審判が範囲に入らないようにすると、打者を選びやすくなります。

3. 点を確かめて修正する

映像の4点が肩と腰の位置に合っているか、コマ送りで確認します。修正したい時刻で「4点を手動で指定・修正する」を開き、各点を指定して保存します。複数の時刻を手動で入力する使い方もできます。

4. 角度と角速度を読む

肩と腰それぞれを結んだ、画像上の線を測ります。角速度の絶対値が大きいほど、その線の向きが速く変化しています。正負は画面内の回る向きです。肩と腰の向きの差や、ピークが現れる時刻を見比べます。

スロー映像は、実際に引き伸ばされた倍率を設定すると実時間に換算できます。元の速さが分からない場合は「通常の速さ」で動画内の変化として読みます。

5. 保存した座標を再解析する

CSVには各時刻の数値を保存します。「座標・条件を保存」のJSONには4点と解析条件を保存します。後から「結果を読み込む」で開けば、動画がなくても閾値や平滑化を変えてグラフを作り直せます。
