HOW TO USE

映像から、動きの違いへ。

観察する場所を変えると、同じ映像から違う動きが見えてきます。

1. デモで動きとグラフをつかむ

スイング、スクワット、腕の曲げ伸ばしからデモを選びます。時刻のバーを動かすと、関節の位置とグラフの線が一緒に変わります。「グラフで見る動き」を切り替えて、肩・腰、肘、膝、体幹を見比べましょう。

2. 動画ファイルかURLを開く

「ファイルから開く」でパソコンやスマートフォンの動画を選びます。MP4・WebMの直接リンクがある場合は「URLから開く」に入力します。開始・終了秒を指定し、「人物の範囲を囲む」で対象を選んでから「AIで動きを解析」を押します。人物の全身が入り、ほかの人をなるべく含まない範囲にします。

3. 関節の位置を確かめて直す

コマ送りで関節の点を確かめます。直したい時刻で「関節を手動で指定・修正する」を開き、関節名のボタンを押して映像上の位置をクリックします。「指定した点を保存」でその時刻の座標を更新します。肘の曲がりには同じ側の肩・肘・手首、膝には腰・膝・足首が必要です。複数の時刻を手動で入力することもできます。

4. 角度と変化の速さを読む

肘・膝は、伸びきった姿勢が180°で、曲げるほど角度が小さくなります。体幹は画像の垂直が0°で、画面の右へ傾くと正です。肩・腰の線は画面の右を0°とし、反時計回りを正にします。角速度は角度が変わる速さを度/秒で表します。

角度は画像の平面に投影された位置から求めます。動作を比べるときは撮影方向とスロー倍率をそろえます。横から撮った動画は肘・膝の曲がり、正面からの動画は左右差の観察に使えます。

5. 保存した座標を再解析する

CSVにはすべての関節の解析値を保存します。JSONには座標・解析条件・選んだグラフを保存します。「結果を読み込む」で開くと、動画がなくても表示する角度や信頼度、平滑化を変えて解析し直せます。以前保存した肩・腰の座標も読み込めます。
