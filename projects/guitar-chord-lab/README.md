# Guitar Chord Lab

音源からギターのコード候補を時刻付きで表示し、音源分離の効果を比較するPython学習プロジェクトです。

## 現在の状態

現在は開発用のひな形です。解析コード、インストール設定、実行可能なNotebookはまだありません。実装と動作確認は[開発仕様](DEVELOPMENT.md)に沿って進めます。

## 初版で目指すこと

- 単独ギター録音から、メジャー／マイナーの24コードを推定する。
- 合奏音源からギターを分離し、同じコード認識処理を適用する。
- 入力音・分離音の再生、クロマグラム、コード推移、CSV保存を用意する。
- 単独ギター、混合音、分離後のギターを同じ条件で比較する。

推定対象は「ギターが演奏しているコード」です。曲全体の和声とは区別します。「コードなし」と「候補を決めきれない状態」も別に扱います。

## 学習の進め方

最初は短い単独ギター音源を対象に、12音の特徴量からコード候補を選ぶ流れを学びます。次に音源分離を接続し、最後に正解注釈との比較実験を行います。

音源分離やコード推定は誤ることがあります。候補を聴き比べて確認できる耳コピ支援ツールを目指します。メロディ採譜、MIDI・TAB譜出力、新しいモデルの学習は初版の対象外です。
