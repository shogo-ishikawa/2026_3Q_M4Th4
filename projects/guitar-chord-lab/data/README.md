# データと正解注釈

現在、音源データや実験用注釈は同梱していません。実装時には、合成デモと正解注釈をコードから生成できるようにします。

## 配置方針

ローカル音源は、このフォルダ以下のraw/等に置きます。音源、分離音、ダウンロードしたデータセット、モデル重みはGitに追加せず、取得方法・出典・利用条件を記録してください。

小さな設定例や、再配布可能な最小限の注釈例は、実装時にexamples/等として追加できます。自分たちの録音や公開データを使う場合も、公開・配布できる範囲を確認してください。

## 正解注釈

正解注釈はstart_s、end_s、chordの3列を持つCSVを基本とします。時刻は注釈対象ファイルの先頭を0秒とし、区間は開始を含み終了を含まないものとして扱います。切り出した場合は、元ファイルに対するオフセットも別に記録します。

コード表記は実装時に統一し、24種類のメジャー／マイナーとNを扱います。例えばC:maj、A:min、Nのような表記を採用できます。異名同音の正規化規則も文書化します。

- Nは「コードなし」です。
- 正解の欠損や対象外コードをNに置き換えません。
- 区間の重複、逆転、音源の範囲外を検証します。
- 単独ギターの認識結果を正解として流用しません。
- 元素材IDと調整用／評価用の区分を保存します。

## 合成デモ

合成デモはプログラムの動作・音名対応・評価処理を確認するために使います。実際のギター録音とは区別し、合成音だけの成功を合奏音源での認識性能として報告しないでください。
