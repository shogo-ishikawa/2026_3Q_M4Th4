# Notebook

実装時に、Google Colabで順に実行できる教材を追加します。現在、実行可能なNotebookやColabリンクはまだありません。

予定している内容は次のとおりです。

1. 単独ギター音源からコード候補を表示する。
2. 混合音からギターを分離し、同じコード認識を行う。
3. 正解注釈を使い、単独音・混合音・分離音を比較する。

各Notebookは、セットアップ、入力、再生、特徴量、推定、保存、設定を変えて試す練習の順で構成します。処理本体はsrc/の関数を呼び、Notebook内へ重複実装しません。

新規Colabからリポジトリまたは配布ZIPを取得し、この作品だけをインストールする手順を用意します。実装後は実際のNotebookパスに対応したリンクを掲載します。
