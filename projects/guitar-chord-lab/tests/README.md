# 検証コード

```bash
pip install -e ".[dev]"     # 作品フォルダで実行
python -m pytest
```

| ファイル | 確かめる内容 |
| --- | --- |
| `test_chords.py` | 24種類のテンプレート、構成音、コード名の正規化、対応外のコードの検出 |
| `test_audio.py` | 切り出し、範囲外の指定、MP3 の読み込み、読み込めない音声ファイルの説明、モノラル化とリサンプリング、保存 |
| `test_recognition.py` | 正弦波の三和音24種類の判定、無音→N、境界の時刻、全体が無音・短すぎる入力、判定保留（区間をまとめず、候補と類似度を残す）、N の区間の類似度、元ファイルの時刻への変換、設定の型と範囲の検証、合成デモ |
| `test_evaluation.py` | 完全一致・不一致・部分的な時間の一致・判定保留・予測なし・注釈の欠損の評価、mir_eval との照合、不正な注釈の検出（行番号、UTF-8 以外の文字コード、列名の空白）、推定結果CSVの読み込み、音源より長い注釈 |
| `test_separation.py` | Demucs 未導入・モデル取得失敗・guitar を出力しないモデル・メモリ不足の説明と後始末、不正な分離の設定、キャッシュ（分離時間の記録を含む）、時間軸 |
| `test_experiment.py` | 音量比を保った混合、時間ずれの推定、元素材単位の分割（同じファイルの切り出し）、比較実験の実行と分離前後の対応付け、元素材ごとの集計、集計ファイルの書き直し、設定の誤り（知らない項目、伴奏IDの重複）の検出、聴き比べ用の音の読み込み（今回の結果にある条件だけ、保存しない設定、書き換えられたファイル、長さの確認） |
| `test_guitarset.py` | JAMS からの注釈の変換、対応外のコードの検出、3度の割合、実験設定の作成、取得の中断・録音IDの誤り・通信エラーの表示 |
| `test_cli_and_demo.py` | 合成デモの生成、`demo`・`analyse`・`separate`・`evaluate` コマンド（切り出し位置の記録、注釈の確認、評価する区間：末尾・途中の予測欠落、切り出し位置、`analysis.json` のない CSV）、エラーの表示 |
| `test_notebook_cells.py` | Notebook のセルをそのまま実行：Notebook 1 のクロマ表示と再生（無音と通常の音）、Notebook 3 の聴き比べ（前の実行のファイルが残った状態での実行し直し） |
| `test_results.py` | JSON の保存、図の文字（日本語のファイル名）、コードの版の記録、配布ZIPの版情報、クロマの表示（無音のフレーム） |

時間のかかる確認は、環境変数を付けたときだけ実行します。

```bash
RUN_DEMUCS_TESTS=1 python -m pytest -m demucs                 # Demucs のモデル取得と実分離
RUN_NETWORK_TESTS=1 python -m pytest tests/test_guitarset.py  # Zenodo からの取得
```

合成音でのテストは、プログラムの動作と音名の対応を確かめるものです。実際のギター録音での精度を示すものではありません。実施した確認と結果は [docs/verification.md](../docs/verification.md) にあります。
