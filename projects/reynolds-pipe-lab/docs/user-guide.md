# Reynolds Flow Labの使い方

管を流れる水の速さと抵抗を、実験を切り替えながら調べます。準備する動画やデータはありません。最初は画面上の「01 中心と壁を比べる」を押してください。

## 最初の3つの操作

1. **中心と壁を比べる**を押します。中心付近の点と壁の近くの点を一つずつ追います。同じ時間で進む距離が大きい点ほど速い流れです。
2. **流速を2倍にする**を押します。下の平均流速U・摩擦係数fD・圧力損失Δpの倍率を比べます。
3. **混ざる流れを考える**を押します。「流体を色分け」と「軌跡」で横方向の動きを見ます。

各実験には短い予想問題と解説があります。予想を選ぶと理由を確認できます。

## 条件を変える

「自分で条件を変える」の数値欄かスライダーでReを指定し、「この条件で実行」を押します。設定途中の値と実行中の値は操作欄で確認できます。

| 操作 | 変わること |
| --- | --- |
| Re | 水の性質と管の太さを固定したまま平均流速を変える |
| 流れの計算方法 | 軸対称層流・3次元SPH・混合の模式モデルを切り替える |
| 計算の細かさ | 半径方向の計算粒子数や3次元の粒子数を変える |
| 人工粘性α | 3次元SPHの数値的な振動を抑える強さを変える |
| 粒子の見せ方 | 中心の薄い断面と円管全体の表示を切り替える |
| 再生速度 | 計算の進む速さを変える |
| 一時停止・再開 | 現在の計算を止める・続ける |
| 初めから | 同じ条件で初期状態へ戻る |

再生を2倍速にする操作と、実験2で水の流速を2倍にする操作は別です。再生速度は画面の進み方です。水の実際の速さは平均流速Uのm/s表示で読みます。

軸対称層流はRe 2,300未満で使います。このモードのままReを上げると混合の模式モデルへ切り替わります。変更した計算方法は操作欄で確認できます。

## グラフを読む

### 中心と壁の速度差

縦軸は中心から壁へ向かう位置r/Rです。中心が0で壁が1です。横軸u/Uは、その場所の速さを基準の平均流速で割った値です。

層流の理論線は放物線です。中心の速さは平均の2倍で、壁ではゼロになります。橙色の点はSPHで計算した流速です。線と点のずれを見ます。

### 摩擦係数と圧力損失

摩擦係数fDは管の抵抗を比べるための単位のない指標です。圧力損失Δpは水を流すために必要な前後の圧力差です。単位はPaです。

層流で流速を2倍にするとReも2倍になります。fD = 64/Reから摩擦係数は半分です。一方で圧力損失の式には流速の2乗が含まれます。結果として圧力損失は2倍になります。

Re–f図と大きな数値欄は円管の参照式を使います。「壁の近くの速度変化」の欄では軸対称SPHで計算した壁勾配と平均流速からfDを求めます。数値計算と理論値の比較に使えます。

### 誤差による一時停止

実験1・2は層流の理論分布から始めます。誤差の表示は、その分布を保てているかを確かめるための値です。誤差の目安を超えると停止します。

「誤差の変化を観察するために続ける」を押すと計算を続けられます。横方向の動きが出た場合も、速度分布や密度の誤差と合わせて読みます。誤差による変化と乱流の現象を読み分けてください。

## 記録を比べる

Re–f図の「式による値を記録」を押すと最大6条件を並べられます。同じReを重ねて記録することはありません。7条件目を記録すると古い条件から入れ替わります。

「記録した値をCSV保存」で表計算ソフトに持ち出せます。流速・摩擦係数・圧力損失・流量・送水動力を比べられます。この比較記録は、このブラウザで次回も使えます。

## 実験を保存して開く

**条件と記録を保存**でJSONを保存します。次の内容を含みます。

- 実行済みのReと計算方法
- 計算の細かさと人工粘性
- 表示設定と選んだ実験
- 最大6条件の比較記録

**保存した実験を開く**でJSONを選ぶと、同じ設定を初期時刻で復元します。「再開」を押すと計算を進められます。途中の粒子配置を残すには**流れの図をPNG保存**を使います。

別のブラウザやパソコンで続けたいときもJSONを使います。

## 4つの計算法を比べる

手法比較ページでは、静止した水が一定の力で流れ始める過程を扱います。

1. 基準の空間分割数を選びます。最初は32がおすすめです。
2. Reと比較する粘性時間θを選びます。
3. 「この条件で比較」を押します。
4. 補正SPH・固定格子・AMR・移動格子を、同じ時刻の解析解と比べます。
5. 分割数を16→32→64と変え、誤差と実際の要素数の変化を確認します。

AMRは必要な場所のセルを分割します。移動格子はセル数を保ったまま境界位置を変えます。始動中は正解の分布も変化します。同じθの解析解と比べることで計算誤差を読めます。

## パソコンで起動する

ZIPを展開し、`v3.2.0` フォルダでターミナルを開きます。

Windows：

```sh
py run.py
```

macOS・Linux：

```sh
python3 run.py
```

自動でブラウザが開かない場合は `http://127.0.0.1:8000/` を開いてください。終了はターミナルで `Ctrl+C` です。
