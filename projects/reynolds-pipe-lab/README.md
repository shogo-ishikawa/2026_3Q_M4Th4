# Reynolds Flow Lab — 管の中の流れ

v3.2.0。水の進む速さと管の抵抗をブラウザで調べる教材です。3つの実験を動かした後に、計算結果と式の関係を確かめます。

[アプリを開く](https://shogo-ishikawa.github.io/2026_3Q_M4Th4/reynolds-pipe-lab/) ／ [詳しい使い方](docs/user-guide.md)

## まず動かす

1. 「01 中心と壁を比べる」を押します。
2. 中心付近と壁付近の点を追い、同じ時間に進む距離を比べます。
3. 「02 流速を2倍にする」を押します。平均流速・摩擦係数・圧力損失の倍率を見ます。
4. 「03 混ざる流れを考える」では色と軌跡を使って混合のイメージを観察します。
5. 調べた条件を記録し、CSVやJSONで保存します。

各実験の「観察したら解説を読む」に、見どころと理由をまとめています。流速・圧力・粘性から知りたい場合は「解説・用語集」を開いてください。

## 3つの実験

| 実験 | 条件と計算 | 見るところ |
| --- | --- | --- |
| 中心と壁を比べる | Re 500。軸対称SPHで層流を計算 | 中心ほど速く、壁に接する流体の速度はゼロになる |
| 流速を2倍にする | Re 1,000。同じ水と管で比較 | 流速は2倍、摩擦係数は半分、圧力損失は2倍になる |
| 混ざる流れを考える | Re 20,000。渦の外力を与えた模式モデル | 流れが横方向にも水を運ぶ様子を色と軌跡で見る |

水の密度は998 kg/m³、動粘性係数は1.004×10⁻⁶ m²/sです。管の直径は20 mmです。圧力損失は長さ1 mへ換算します。水の性質と管の寸法をそろえ、流速を変えてReを調整します。

## 数値とグラフを読む

| 表示 | 求め方 |
| --- | --- |
| 粒子の動き・速度分布の橙の点 | 数値計算した流速 |
| 大きなU・fD・Δpの数値欄、倍率欄、Re–f図 | 設定したReと円管の参照式 |
| 壁の近くの速度変化から求めたfD | 軸対称SPHの壁勾配と数値的な断面平均流速から推定 |
| 速度分布の線 | 層流の理論解。模式モデルでは与えた目標分布 |
| 誤差の表示 | 数値速度分布と同じ条件の層流理論解との差 |

画面の流速は基準の平均流速Uで割ったu/Uです。実験1から2へ移っても規格化した分布の形は同じです。実際の速さはm/sの数値で確認できます。

軸対称SPHでは半径方向の16〜128粒子で流速を求めます。画面に見える多数の点は、その流速で動く目印です。初めは定常層流の理論分布を与えます。その後は一定の駆動力と粘性の式で計算を進めます。時刻や粒子数を変え、理論分布が保たれるかを比べられます。

横方向の流速をゼロとするのは軸対称層流の前提です。混合の模式モデルは横方向の動きを外力で与えます。3次元SPHの自由実験では密度と圧力も計算します。長時間で誤差が増える場合があるため、速度分布と誤差の表示を合わせて読みます。

## 保存と再開

- **条件と記録を保存**：実行済みのRe・計算方法・計算の細かさ・人工粘性・表示設定・学習ステップ・比較記録をJSONへ保存します。
- **保存した実験を開く**：JSONから条件を復元します。初期時刻で一時停止するので「再開」を押して計算を進めます。
- **流れの図をPNG保存**：現在の粒子表示を画像にします。
- **CSV保存**：記録した円管の参照値を表計算ソフトで比較できます。

比較記録は最大6条件です。このブラウザで次回も使えます。別のブラウザへ持ち出す場合はJSONを保存してください。JSONは実験の設定を保存するファイルです。途中の粒子配置はPNGで残せます。

## 4つの計算法を比べる

[手法比較ページ](https://shogo-ishikawa.github.io/2026_3Q_M4Th4/reynolds-pipe-lab/methods.html)では、静止した水が一定の力で流れ始める過程を解きます。

- 補正SPH：近い粒子の情報から微分を近似します。
- 固定格子・有限体積法：固定した領域ごとに粘性の力を足し合わせます。
- AMR・適応格子：速度が大きく変化する場所を細かくします。
- 移動格子：セル数を保ち、境界位置を再配置します。

全て半径方向1次元の層流モデルです。同じ時刻の解析解との差、実際の要素数、壁面摩擦を比べます。解析解にも時間による変化があるため、同じ時刻で比較することが大切です。

## ローカルで開く

ZIPを展開すると `v3.2.0` フォルダができます。Python 3の標準ライブラリで起動できます。

Windows：

```sh
py run.py
```

macOS・Linux：

```sh
python3 run.py
```

ブラウザが自動で開かない場合は `http://127.0.0.1:8000/` を開きます。終了はターミナルで `Ctrl+C` です。ローカルサーバーを通してJavaScriptモジュールを読み込みます。

配置例：`/Users/shogo/Dropbox/share_data/open_material/misc/apps/ReynoldsFlowLab/v3.2.0`

コードは[クラスのGitHubリポジトリ](https://github.com/shogo-ishikawa/2026_3Q_M4Th4)の `projects/reynolds-pipe-lab/` で管理します。Gitの通信はHTTPSを使います。
