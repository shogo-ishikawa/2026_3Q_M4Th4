# 午前0時17分の試作機 — ASTERION

九つの専門分野から一つを選び、地下研究施設の謎を追う日本語ミステリーです。D20の判定、体力・専門知識・集中力、手掛かりと残り31分を使って五つの結末を探ります。

[ゲームで遊ぶ](https://shogo-ishikawa.github.io/2026_3Q_M4Th4/asterion-story/) ／ [遊び方](guide.html)

## はじめ方

「調査を始める」から専門を選びます。文章を読んだら調査を選び、成功率と時間・消耗を確認して判定します。通常の章では二つまで異なる調査ができ、一つ調べた時点で次の章へ進めます。慎重・標準・大胆の進め方と、各章一回の休憩・専門能力を使い分けます。時間は行動ごとに進むため、読む速さは結果に影響しません。

調査結果の増減はその場で表示します。状態は判定に反映され、証拠・理解度・具体的な手掛かりは最後の操作に関わります。低い体力や時間切れでも最後の操作へ進めます。

## 起動と保存

配布ZIPを展開した `v1.0.0` で `python3 run.py`（Windowsは `py run.py`）を実行します。Python標準ライブラリだけで起動します。終了は `Ctrl+C` です。

端末内の自動保存と手動セーブ、JSON記録の書出し・読込に対応します。判定済みの結果と乱数の状態も引き継ぎます。別の端末へ移す場合はJSONを使ってください。

配置例：`/Users/shogo/Dropbox/share_data/open_material/misc/apps/Asterion/v1.0.0`

`bash sync_to_github.sh` で既存のクラスリポジトリへHTTPSで同期できます。

## コードを読む

| ファイル | 役割 |
| --- | --- |
| `data.js` | 専門分野・物語・行動・手掛かり・結末 |
| `engine.js` | 判定・状態変化・時間・保存データの検証 |
| `app.js` | 画面・操作・端末内保存 |
| `tests/engine.test.mjs` | 判定と進行、結末への到達、保存・再開の検証 |

`node --test tests/*.test.mjs` でゲームの検証を実行できます。画面と計算を分けているため、物語データや難易度を変えた後も同じ関数を確かめられます。

背景イラストは本作のために生成した画像です。物語の舞台は青嵐大学の地下研究施設です。
