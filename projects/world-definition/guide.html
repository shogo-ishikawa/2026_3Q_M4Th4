WORLD DEFINITION / v1.0.0

世界を変える、最初の一歩。

目の前の川を、どう渡りますか。物体と動作を組み合わせて、進める道を作ってみましょう。このガイドでは操作から順に説明します。

始め方操作ルールヒント困ったとき作品について

FIRST PLAY

まずは、そのまま遊んでみましょう

ゲームの index.html を開き、最初の説明から遊び始めます。標準モードは、ブラウザだけで動きます。インストールやログイン、AIモデルの準備は必要ありません。

  1. 少し歩いてみる

    WASD・矢印キー、または画面の方向ボタンで移動します。最初は川の手前まで進んでみてください。

  2. ルールを作る

    研究室で「物体」と「動作」を選び、ルールを適用します。選択しただけでは世界は変わりません。

  3. 変化を確かめる

    色だけでなく、通れる場所や物体の扱い方が変わります。画面の目標と有効なルールも確認しましょう。

  4. 結晶から、その先へ

    結晶を拾うと「加熱」が使えるようになります。金属ゲートを開き、その奥のゴールを目指します。

行き詰まったときは、ゲーム画面のヒントや、この下の「ヒント」を一つずつ開いてください。最初から解答を読む必要はありません。

スマートフォン・タブレットの場合

画面の方向ボタンを押し続けて移動します。「操作」ボタンがEキーに相当します。浮遊物体を運ぶときは、操作ボタンと方向ボタンを同時に押してください。画面が狭い場合、研究室はゲーム画面の下に並びます。

RULE WORKSHOP

物体と動作を組み合わせる

研究室では、物体を一つと、動作を最大3つ選びます。「ルールを適用」を押したら、何が変わったかをゲーム画面で確かめます。動作を外す場合も、選び直してから適用してください。

物体使える動作と効果
水凍結・固体化で川を渡れます。発光・脈動では光の見え方が変わります。
石・木浮遊すると、近くでE＋移動を使って運べます。川へ置くと足場になります。成長で大きくなり、発光・脈動で光の見え方が変わります。
炎浮遊で位置が上がり、移動で左右に動き、成長で大きくなります。凍結で触れても戻されなくなります。発光・脈動は見た目を変えます。加熱は結晶取得後、ゲートを開くために使えます。

前のルールは、どうなりますか？

ルールは物体ごとに残ります。水の凍結を適用した後、炎に加熱を適用しても、水の凍結は続きます。同じ物体へもう一度適用すると、その物体の動作を置き換えます。川の途中で足場を失う変更は受け付けないため、岸に戻ってから試してください。

炎に触れたら？

プレイヤーはスタート地点に戻ります。ゲームオーバーにはなりません。どこに炎があるかを確認して、進む道を変えてみましょう。

AIは何をしますか？

標準モードでは、選んだ動作から名前と説明を組み立てます。任意のローカルAI連携では、その名前と説明をOllamaが補助します。AIがゲームのプログラムを書き換える仕組みではありません。遊びに必要な効果は、どちらのモードでも同じです。

HINTS

少しずつ、手掛かりを見る

自分で考える時間も楽しめるよう、ヒントと攻略例を分けています。必要なところだけ開いてください。

ヒント1：川の向こうへ行きたい

水そのものを変える方法と、別の物体を足場にする方法があります。「通れない」という性質を、どの動作で変えられるでしょうか。

ヒント2：浮かせた物体をどう使う？

浮遊した石や木の近くへ行き、Eを押しながら移動してみてください。物体を川へ運べます。川の中央付近でEを離し、できた足場を通ってみましょう。

ヒント3：ゲートが開かない

まず結晶を取ると「加熱」が解放されます。「炎」に「加熱」を適用し、ゲートのすぐ手前でEを押し続けてください。進み具合の表示が満たされると開きます。

攻略例を見る（ここからは解答です）
  1. 研究室で「水」と「凍結」または「固体化」を選び、ルールを適用します。
  2. 川を渡り、左側にある結晶を回収します。
  3. 研究室で「炎」と、解放された「加熱」を選び、ルールを適用します。水のルールは残ります。
  4. 中央の金属ゲートの近くでEを押し続け、ゲートを開きます。
  5. ゲートの奥の「GOAL」に入るとクリアです。

別の解き方として、石や木を浮遊させて川へ運び、足場にできます。クリアした後は、異なるルールで同じ場所へ進めるか試してみましょう。

TROUBLESHOOTING

困ったときは

キーを押しても動きません

最初の説明やヘルプを閉じ、ゲーム画面を一度クリックしてください。壁や川に向かっている場合も、その方向へは進めません。別の方向へ少し動けるかを確かめましょう。

物体を選びましたが、変化しません

物体に加えて、動作を一つ以上選んでください。その後「ルールを適用」を押します。発光や脈動だけでは足場はできません。選択できない動作や、まだ解放されていない加熱も確認してください。

石や木を運べません

その物体に浮遊を適用したか確認します。プレイヤーを物体へ近づけ、Eを押したまま方向キーを押してください。画面のボタンでは「操作」と方向を同時に押します。

AIへの接続で止まります

通常の公開ページはAIを使わず遊べます。ローカルAI連携を選んでいる場合は、その選択を外して標準モードで試してください。ローカルAIの導入・モデル設定は、同じフォルダのREADMEにあります。公開ページから、自分のコンピューターのOllamaには接続しません。

ダウンロードしたページが表示されません

ZIPは先に解凍してください。index.htmlだけを移動せず、engine.js、app.js、style.cssを含むフォルダをまとめて置きます。JavaScriptを有効にしたブラウザで開いてください。

最初からやり直したいです

ゲームのやり直しボタン、またはRキーを使います。確認後に、結晶、適用したルール、物体の位置、ゲートを初期状態へ戻します。ブラウザを再読み込みした場合も最初から始まります。

ABOUT THIS WORK

このゲームが生まれた考え方

2026年度「計算科学基礎」の学生制作をもとにした作品です。「障害物に合わせて動くだけでなく、障害物の性質を変えられないか」という問いから、物体と動詞で世界を変える仕組みが生まれました。

C++・raylibでの試作とJavaScript・Canvas版を引き継ぎ、公開版ではインストール不要の動作、物体ごとのルール保持、操作や当たり判定、ガイドを整えました。現在遊べるのは1ステージです。自由な文章によるルールの作成や複数ステージは、今後の発展案です。

仕組みに興味が湧いたら、コードの読み方と変更して試す課題（オンライン）も見てみてください。色や速さを一つ変えるだけでも、遊びやすさがどう変わるかを確かめられます。
