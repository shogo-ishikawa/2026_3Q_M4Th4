WORLD DEFINITION / v1.1.0

定義を変えると、世界が変わる。

水を固め、石を浮かせ、木の光を運ぶ。見える変化を手掛かりに、5つのステージの道を作りましょう。

FIRST PLAY

まずはステージ1を遊んでみましょう

ゲーム画面を開き、最初の説明から遊び始めます。インストールやログイン、AIモデルの準備は必要ありません。

  1. 川まで歩く

    WASD・矢印キー、または画面の方向ボタンで移動します。まだ川は渡れません。

  2. 定義を適用する

    研究室で「水」と「固体化」を選び、「ルールを適用」を押します。選ぶだけでは世界は変わりません。

  3. 変わった場所を進む

    水面が通路へ変わったら川を渡り、青い結晶に近づいて拾います。

  4. ゲートを開いてゴールへ

    結晶で「加熱」が解放されます。「炎＋加熱」を適用し、ゲートの近くで立ち止まってEを長押しします。

クリアすると次のステージが解放されます。先のステージでは水の定義が封印され、物体を運んで仕掛けを解く必要があります。

金の欠片は各ステージに2個あります。取らなくてもクリアできるので、最初はゴールを目指して大丈夫です。

RULE WORKSHOP

定義すると、何が変わるか

研究室では物体を一つと動作を最大3つ選びます。「ルールを適用」を押したら、対象の形や動き、光を見てみましょう。適用中の動作は物体のバッジでも確認できます。

動作見える変化と使い方
凍結水面に氷の結晶や割れ目が現れ、歩けるようになります。炎に使うと消火され、安全に近づけます。
固体化水面が石張りの通路へ変わります。ステージ1では川全体を渡れます。
浮遊石・木が地面から浮き、影と離れて見えます。近くでE＋移動を使うと運べます。炎は上へ浮きます。
成長石・木や炎が大きくなります。物体の足場は幅と長さも広がり、広い川で役立ちます。
発光対象の周りに光が広がります。光の紋章へ指定の物体を運ぶと、その光を届けられます。
脈動光が周期的に変わり、波紋が広がります。共鳴盤では発光と一緒に使います。
移動炎が左右に往復します。軌跡も見ながら通る場所を判断できます。
加熱炎が熱を帯び、熱波が現れます。ゲートの近くでEを長押しすると加熱の線と進み具合が表示されます。

対象ごとに使える動作が違います

物体基本の動作
水凍結・固体化・発光・脈動。ステージ2以降は凍結と固体化が封印されています。
石・木浮遊・成長・発光・脈動。
炎浮遊・移動・成長・発光・凍結・脈動・加熱。加熱は結晶を取ると使えます。

炎の「凍結」と「加熱」、水の「凍結」と「固体化」は同時に定義できません。両方を選んだ場合は、どちらかを外してから適用してください。

前のルールはどうなりますか？

ルールは物体ごとに残ります。木を浮遊させた後で炎を加熱しても、木の浮遊は続きます。同じ物体に別のルールを適用すると、その物体の動作を置き換えます。動作を一つだけ外したいときも、残したい動作を選んでから適用してください。

今いる足場を失う変更は受け付けません。足場の定義を変えたいときはいったん岸へ戻ってください。

受信盤はどう作動しますか？

盤に書かれた物体を近くへ運び、必要な動作を約1秒間届けると点灯します。進み具合の表示が満たされるまで待ちましょう。一度点灯した盤は、その後も点灯したままです。受信盤のあるステージでは全ての盤を点灯させてからゲートを加熱します。

AIは何をしますか？

標準モードでは選んだ動作から名前と説明を組み立てます。任意のローカルAI連携では、その名前と説明をOllamaが補助します。ゲームの効果はどちらのモードでも同じです。AIが自由にプログラムを書き換える機能はありません。

FIVE STAGES

ステージ別の手掛かり

先に目的とヒントを読み、必要なときだけ攻略例を開いてください。ここで挙げる手順以外の解き方も試せます。

1：封印されたゴール

川の向こうの青い結晶を拾い、金属ゲートを開きます。世界を変える操作に慣れるステージです。

ヒント：川を渡る方法を考える

水そのものを変える方法と、別の物体を足場にする方法があります。凍結や固体化の見え方も比べてみましょう。

攻略例を見る（ステージ1の解答）
  1. 「水＋凍結」または「水＋固体化」を適用します。
  2. 川を渡って左側の青い結晶を拾います。
  3. 「炎＋加熱」を適用し、中央のゲートの近くで立ち止まってEを長押しします。
  4. 開いたゲートを通り、GOALへ進みます。

石や木を浮遊させて川へ運び、足場にする方法でも渡れます。

2：石の渡し場

水の凍結と固体化が封印されています。石や木を動かして道を作ります。

ヒント：物体を川へ運ぶ

石に浮遊を適用するとE＋移動で運べます。川へ近づけるだけでなく、足場が対岸までつながる位置を探しましょう。

攻略例を見る（ステージ2の解答）
  1. 石に浮遊を適用し、石の近くへ行きます。
  2. E＋方向キーで石を川の中央へ運び、足場を渡ります。成長を組み合わせると足場が広がります。
  3. 対岸の結晶を回収し、炎に加熱を適用します。
  4. 右側のゲートの近くでEを長押しし、開いた先のGOALへ進みます。

3：光を運ぶ庭

結晶のほかに光の紋章を点灯させます。光源になる木を届けましょう。

ヒント：発光だけでは届かない

紋章が求めるのは木の光です。木を発光させても遠ければ作動しません。浮遊も組み合わせると光源を運べます。

攻略例を見る（ステージ3の解答）
  1. 木に浮遊と発光を適用します。
  2. 木を川の足場として運び、対岸へ渡ります。
  3. 木をさらに北側の光の紋章へ運びます。近くで約1秒待ち、紋章が点灯したことを確認します。
  4. 青い結晶も回収し、炎に加熱を適用します。
  5. ゲートの近くでEを長押しし、GOALへ進みます。

先に石を橋にしてから、木を運ぶ方法もあります。

4：脈動の回廊

共鳴盤は石の発光と脈動を求めています。川を渡る動作と合わせて組み立てます。

ヒント：最大3つの動作を使う

必要なのは「運ぶ」「光を出す」「周期的に変化する」という3つの性質です。石にどの動作を組み合わせればよいでしょうか。

攻略例を見る（ステージ4の解答）
  1. 石に浮遊・発光・脈動を適用します。
  2. 石を川へ運び、足場を使って対岸へ渡ります。
  3. 石を共鳴盤の近くへ運び、約1秒待って点灯させます。
  4. 結晶を回収し、炎に加熱を適用します。
  5. ゲートを加熱して開き、GOALへ進みます。

5：最後の定義

広い川と2つの受信盤が登場します。石と木に別々の役割を持たせましょう。

ヒント：一つの物体に全部を任せない

石には大きさ、木には光と脈動が求められています。成長した足場は幅と長さが広がります。物体ごとに定義を残せることも思い出してください。

攻略例を見る（ステージ5の解答）
  1. 石に浮遊と成長を適用します。広い川の中央へ運び、まずは橋として残します。
  2. 木に浮遊・発光・脈動を適用します。石の橋を使いながら木を対岸へ運び、木の受信盤を点灯させます。
  3. 石を川から北側の台座へ運び、約1秒待って作動させます。木を渡し終えるまで石の橋を残すと往復しやすくなります。
  4. 青い結晶を回収し、両方の盤が作動したことを確認します。
  5. 炎に加熱を適用してゲートの近くでEを長押しし、最後のGOALへ進みます。

一度点灯させた盤は消えません。物体の運搬と往復の順番を変えてみてもよいでしょう。

YOUR PROGRESS

クリアした後も試せます

クリアすると次のステージが解放されます。解放済みのステージはステージ選択から遊び直せます。金の欠片を集める、少ない定義回数で解く、別の物体で渡るなど、目的を変えて試してみましょう。時間制限はありません。

何が保存されますか？

ステージの解放状況とクリア記録を、利用中のブラウザに保存します。記録には定義回数、集めた欠片、クリア時間が含まれます。プレイヤーの位置や途中の定義は保存せず、再読み込み後はステージを選んで最初から遊びます。

記録は別の端末やブラウザへ自動では共有されません。サイトデータを消すと記録も消えます。保存を利用できない環境でもゲームは続けられます。

TROUBLESHOOTING

困ったときは

キーを押しても動きません

最初の説明やヘルプを閉じ、ゲーム画面を一度クリックしてください。壁や川に向かっている場合も、その方向へは進めません。別の方向へ少し動けるか確かめましょう。

定義を選びましたが変化しません

物体と動作を選んだ後に「ルールを適用」を押してください。対象のバッジと研究室の適用中のルールも確認します。足場を失う変更が拒否された場合は、いったん岸へ戻ってからやり直します。

水を凍らせられません

ステージ2以降では水の凍結と固体化が封印されています。石や木を浮遊させ、運んで足場にしてください。選べない動作は研究室に表示されます。

石や木を運べません

その物体に浮遊を適用したか確認します。プレイヤーを近づけてEを押したまま移動してください。画面のボタンでは「操作」と方向を同時に押します。今いる足場を支えられなくなる動きは止められるため、先に岸へ降りてから物体を運びましょう。

受信盤が点灯しません

盤が指定した物体と動作を確認してください。十分近くへ運び、約1秒待ちます。光の紋章は木の発光、共鳴盤は石の発光と脈動、最後の2つの盤は石の成長と木の発光・脈動が必要です。

結晶を取ったのにゲートが開きません

受信盤のあるステージでは全ての盤を点灯させてください。その後「炎＋加熱」を適用し、ゲートの近くで立ち止まってEを押し続けます。移動しながらでは加熱しません。

炎に触れました

プレイヤーは戻されますがゲームオーバーにはなりません。適用したルールや回収済みの結晶は残ります。炎を凍結して消火する方法もあります。

動きや明滅を控えめにしたいです

端末やブラウザの「視差効果を減らす」などの設定を利用できます。動きを控える表示でも、適用中のバッジや形の変化から状態を確認できます。

クリア記録が残りません

同じブラウザと同じ公開ページで開いているか確認します。サイトデータの削除や保存を制限する設定で記録が消えることがあります。保存できなくても、その回のプレイは続けられます。

AIへの接続に失敗します

公開ページはAIを使わず遊べます。ローカルAI連携を選んでいる場合は選択を外してみてください。導入方法はREADME（オンライン）にあります。接続に失敗しても標準の名前と説明で遊べます。

ダウンロードしたページが表示されません

ZIPを先に解凍してください。index.htmlだけを移動せず、engine.js、renderer.js、app.js、style.cssを含むフォルダをまとめて置きます。JavaScriptを有効にしたブラウザで開いてください。

現在のステージを最初からやり直したいです

やり直しボタン、またはRキーを使います。確認後、結晶、欠片、適用したルール、物体、ゲートを初期状態へ戻します。保存済みの解放状況とクリア記録は残ります。

ABOUT THIS WORK

このゲームが生まれた考え方

2026年度「計算科学基礎」の学生制作をもとにした作品です。「障害物に合わせて動くだけでなく、障害物の性質を変えられないか」という問いから、物体と動詞で世界を変える仕組みが生まれました。

C++・raylibの試作とJavaScript・Canvas版を引き継ぎ、公開版ではインストール不要の動作や操作案内を整えました。v1.1.0は原作のステージを残し、定義による変化を見やすくしたうえで4つのステージを追加しています。自由な文章から新しいゲーム処理を作る機能はありません。

仕組みに興味が湧いたら、コードの読み方と変更して試す課題（オンライン）も見てみてください。川の幅や受信盤の位置を一つ変えるだけでも、必要な運び方が変わります。
