# 計算科学基礎：2026年度 第3クォーター

Pythonの基礎を学んだ学生が、AIや教員の支援を受けながら制作するプログラムと作品をまとめるリポジトリです。作品ごとに実行環境と説明を分け、コードを読み、条件を変え、結果を確かめながら開発します。

## 作品一覧

| 作品 | 内容 | 状態 |
| --- | --- | --- |
| [Guitar Chord Lab](projects/guitar-chord-lab/) | ギターの音源分離とコード認識、分離前後の比較実験 | 開発ひな形・仕様あり。アプリ本体は未実装 |

実行できるNotebookやコマンドは、実装・動作確認後に各作品のREADMEへ掲載します。

## 使い方

1. 作品一覧から、取り組む作品のフォルダを開きます。
2. その作品のREADMEに従い、Google Colabまたはローカル環境を準備します。
3. 例を実行した後、関数や設定を一つずつ変更して結果を比較します。

各作品の依存ライブラリは、その作品に必要なものだけをインストールします。

## リポジトリの構成

| 配置先 | 用途 |
| --- | --- |
| `projects/<作品名>/` | 作品ごとのソース、Notebook、説明、テスト |
| `docs/adding-projects.md` | 新しい作品を追加する手順 |
| `AGENTS.md` | AIを使った開発にも適用する共通ルール |
| `CLAUDE.md` | Claude Codeが共通ルールを読み込む入口 |

新しい作品を追加する場合は、[追加手順](docs/adding-projects.md)を参照してください。

## 共同開発

作品や変更内容に応じたブランチで作業し、プルリクエストで変更内容と確認結果を共有します。他の作品も利用する共通ファイルを変更する場合は、その理由と影響を説明してください。

このリポジトリは公開されています。学籍番号、成績、個人情報、認証情報、内部連絡は掲載しません。音源やモデル重み、生成した解析結果は原則としてGitに含めず、入手方法や生成方法を記録します。
